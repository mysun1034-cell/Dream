인수인계 문서가 제안한 `02_resume_ko.md`와 `03_resume_en.md`는 만들지 않았다. 이력서 정본은 HTML 한 벌이다. 같은 내용을 두 곳에 두면 서로 어긋나기 때문이다.

## 상태 표기

| 표기 | 뜻 |
|---|---|
| 본인 확인 | 본인이 직접 말하거나 정정한 사실 |
| 기록 확인 | 저장소, 공식 문서, 공고 원문으로 확인한 사실. 확인일과 출처를 같이 적는다 |
| 기존 초안 | 이전 이력서에 있지만 아직 증빙을 보지 않은 내용 |
| 부분 확인 | 일부만 확인된 내용 |
| 확인 필요 | 제출하기 전에 원본으로 확인해야 하는 내용 |

정보가 서로 다르면 다음 순서로 따른다.

1. 본인의 최신 정정
2. 본인의 이전 설명
3. 기록
4. 기존 초안
5. 제안

사실이 바뀌면 이전 내용을 지우지 않고 정정 이력에 남긴다.
