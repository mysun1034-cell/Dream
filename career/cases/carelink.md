## CASE-001: 반올림 방식 하나가 청구 금액을 틀리게 만드는 문제를 막은 일

| 항목 | 내용 |
|---|---|
| 상태 | 구현과 테스트 완료 (공단 제출 명세 쪽은 외부 연동이 남음) |
| 제품·범위 | EdenCare 장기요양 ERP의 청구·급여 금액 계산 |
| 근거 규정 | 청구심사고시 60128, 수가 고시 60122 |

### 무엇이 문제였나

파이썬 기본 `round()`는 **은행가 반올림**이다. 0.5를 짝수 쪽으로 보내서 `round(2.5)`는 2가 된다. 고시나 세무 조문 어디에도 없는 방식이다.

그래서 0.5 경계마다 1원씩 어긋난다. 청구는 1원 단위로 검산하기 때문에, 수천 건이 쌓이면 반려나 환수로 이어질 수 있다. 급여 계산에서도 분쟁이 생기면 계산 근거를 댈 수 없다.

### 무엇을 했나

- **금액 끝처리를 한 모듈(`services/money.py`)로 모았다.** 모든 계산이 이 모듈을 거친다. 소수 오차를 막으려고 `Decimal`로 계산한다.
- **건별 계산**(수가, 본인부담, 급여, 세금, 감가상각)은 1원 단위 사사오입으로 바로잡았다.
- **공단 제출 명세의 기재 규칙**은 조문 문구대로 따로 구현했다.
  - 청구 명세 기재 금액: 시설급여는 산정총액의 80%, 재가급여는 85%. **10원 미만 반올림.**
  - 가산금액 기재: 10원 미만 반올림.
  - 진찰비 본인부담 기재: 10원 미만 **절사**.
- **돈 계산 파일에서 기본 `round(` 사용을 테스트로 영구 차단했다.** 누가 나중에 무심코 써도 검증에서 걸린다.
- 조문 문구를 코드 주석에 그대로 인용했다. "출처 없는 법정 수치는 배포하지 않는다"는 규칙의 한 사례다.

### 검증

- 금액 끝처리 전수 테스트 (`tests/test_money_rounding.py`).
- 2026-09-14 전체 검증에서 테스트 1,582건 통과.

### 한계

- 건별 계산을 1원 단위로 할지 10원 단위로 할지는 조문으로 추가 확정되면 이 모듈에서만 바꾼다 (레지스트리 R-08b).
- 명세를 실제로 제출하는 연동(EDI)과 계약 의사 확인은 외부 요인이라 남아 있다.

### 면접에서 나눠 말할 것

- **본인이 판단한 것:** 확인 필요. 문제를 발견한 경위, 조문을 찾아 규칙을 정한 과정.
- **AI 에이전트와 함께 한 것:** 확인 필요. 구현, 테스트 작성 등.

### 증빙 (비공개 저장소)

- `services/money.py`
- `tests/test_money_rounding.py`
- `docs/결함_작업_레지스트리.md`의 R-08, R-08b

## CASE-002: 장기요양 ERP를 문서자동화 시스템으로 전환한 일

| 항목 | 내용 |
|---|---|
| 상태 | 전환 완료, 요구사항 분석 중 |
| 기간 | 2026-09-14– |
| 배경 | 교육과정 프로젝트로 부산벤처기업협회의 출장복명서·지출결의서 작성을 자동화하는 과제를 맡음 |

### 무엇을 했나

- **전환 전에 기존 시스템을 전체 검증했다.** 검증 게이트 21개와 테스트 1,582건이 모두 통과한 커밋을 기준점으로 삼고, 커밋 이력 전체를 가진 새 저장소로 분리했다.
- **장기요양 도메인 코드를 모두 걷어내고** 인증 같은 플랫폼 커널만 남겼다 (`9e8bf8d`).
- **최소 부팅 골격을 만들었다** (`4dd2e43`): 테이블 7개, 2단 인증.
- **협회가 실제로 쓰는 양식과 규정을 받아 분석했다.** 결재 양식, 계정과목표, 여비 규정이다.

### 분석에서 나온 판단

- **과제 설명서의 예시 값이 실제 계정과목표에 없었다.** 그래서 입력 선택지는 설명서가 아니라 협회의 실제 표를 기준으로 만들기로 했다.
- **결재선이 문서마다 달랐다.** 그래서 결재선 템플릿을 하나로 공유하지 않고 문서 종류별로 두기로 했다.
- **여비 규정의 교통비 기준을 원자료와 대조했다.** 공시 운임표와 규정 금액이 일치하는지 확인했다.

### 한계와 다음 일

- 아직 사용자가 쓰는 단계가 아니다. 도입 전후의 작성 시간과 오류를 비교할 기준을 먼저 정해야 한다.

### 면접에서 나눠 말할 것

- **본인이 판단한 것:** 확인 필요. 전환을 결정한 이유, 실제 양식을 기준으로 삼기로 한 판단.
- **AI 에이전트와 함께 한 것:** 확인 필요. 양식 파일 판독, 코드 삭제 작업 등.
