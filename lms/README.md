## 1. 순서 원칙 — 왜 또 바뀌는가

| 목표 | 올바른 순서 | 이유 |
|------|-------------|------|
| 복습 | 최신 과목부터 | 기억이 살아있어 복구가 쌈 |
| **제작** | **의존성순** | 전제가 없으면 **코드가 안 돌아감** |

**제작에서 최신순이 깨지는 지점:** LLM 핵심기술 Day 2는
`softmax(QKᵀ/√d_k)V`를 직접 짜서 **`nn.MultiheadAttention`과 값이 같은지 검증**합니다.
PyTorch 텐서·autograd를 모르면 **첫 줄부터 못 씁니다.** → PyTorch가 먼저입니다.

```
① LLM API      (Python만, 의존성 0)      ← 현재 수업이라 지금 필요
② PyTorch NLP  (①과 독립)                ← ③의 전제
③ Transformer  (②가 전제)                ← 면접 핵심 카드
④ Spring AI    (Java, 독립 트랙)          ← EDENING 실무 직결
⑤ ML/DL 기초   (Keras, 독립 트랙)         ← 기초 소양 · 시간 부족 시 축소 대상
```

### ② `nlp-from-scratch` — PyTorch 기초

| | |
|---|---|
| **출처** | PyTorch와 자연어 처리 Day 1~4 (07-21~24) + 혼공 Ch.9 |
| **전제** | Python. GPU 없어도 됨 (환경구축 가이드는 WSL2+CUDA 기준이지만 CPU로 가능) |
| **최종 형태** | 토큰화 → 임베딩 → RNN → LSTM/GRU, IMDB 감정분류 |

| # | 마일스톤 | 통과 기준 |
|--:|----------|-----------|
| 1 | 텐서 · autograd | 기울기가 자동으로 흐르는 것을 직접 확인 |
| 2 | **학습 루프 5단계 직접 쓰기** ★ | `model.fit()` 한 줄 = 예측·손실·zero_grad·backward·step 다섯 줄 |
| 3 | 붓꽃 분류 완주 | 데이터→배치→모델→학습→평가→손실곡선 |
| 4 | 와인 데이터로 갈아끼우기 | 특성 개수가 달라 나는 에러의 숫자를 **설명할 수 있음** |
| 5 | 토큰화 → 어휘사전 → 패딩 → DataLoader | 내 문장 20개로 파이프라인 재구성 |
| 6 | one-hot의 한계 → 단어 임베딩 | 왜 임베딩인지 말로 설명 |
| 7 | RNN 셀 — 식 하나 | 은닉 상태가 순서를 나르는 것 |
| 8 | LSTM · GRU | gate가 무엇을 지키는지 + RNN과 성능 비교 |
| 9 | 커스텀 `Dataset` | `__len__` / `__getitem__` 직접 구현 |

### ③ `transformer-from-paper` — ★ 면접 핵심 카드

| | |
|---|---|
| **출처** | LLM 핵심기술 Day 1~5 (07-28~08-13) + 혼공 Ch.10 |
| **전제** | ② 완료 · `transformers` · `klue/bert-base` 내려받기 |
| **최종 형태** | 논문 수식을 직접 구현하고 **HuggingFace 실물과 값을 대조**한 레포 |

| # | 마일스톤 | 통과 기준 |
|--:|----------|-----------|
| 1 | context vector의 병목 재현 | 문장을 벡터 하나에 눌러 담으면 왜 깨지는지 |
| 2 | 어텐션 손계산 + 히트맵 | **재정렬 포맷**으로 뽑기(단조로 하면 대각선만 나옴) · 어느 글자가 어디를 봤나 설명 |
| 3 | **`softmax(QKᵀ/√d_k)V` 직접 타이핑** ★★★ | `nn.MultiheadAttention`과 **값이 일치** |
| 4 | √d_k가 없으면 어떻게 되나 | 분산 실측 + softmax 포화 비교 그래프 |
| 5 | 위치 인코딩 (논문 §3.5) | 셀프 어텐션이 순서를 모른다는 것을 실험으로 |
| 6 | 잔차 연결 · 층 정규화 · FFN | 더 깊게 쌓아 잔차가 정말 필요한지 확인 |
| 7 | **진짜 BERT와 대조** | 내 블록 ↔ `klue/bert-base` 12층, 개수까지 맞추기 |
| 8 | BERT / GPT / BART — 헤드 붙이기 | 같은 블록인데 하는 일이 다른 이유 |
| 9 | 서브워드 토크나이저 | 32,000 조각 · 한글이 영어보다 조각 많은 이유 |
| 10 | 생성 = 다음 한 토큰의 반복 | greedy / top_p / temperature 3종 비교표 |

|---|---|
| **출처** | Spring AI Day 1~6 (07-02~09) |
