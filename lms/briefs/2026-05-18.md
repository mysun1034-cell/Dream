Git/GitHub 기반 학습 기록 체계 구축
공개

지식 목표

버전 관리가 왜 필요한지 설명할 수 있다. Git의 세 영역(Working Directory, Staging Area, Repository) 모델을 이해한다.

기능 목표

터미널에서 git 기본 명령(init, add, commit, log, status, branch, switch)을 직접 실행할 수 있다. VSCode Source Control 패널로 같은 작업을 수행할 수 있다. GitHub에 원격 저장소를 만들고 로컬 이력을 push할 수 있다.

산출물 목표

개인 GitHub 저장소를 생성하고 커밋 이력이 포함된 상태로 LMS에 URL을 제출한다. README.md가 포함되어야 한다.

git (CLI)
GitHub
VSCode (Source Control 패널)
터미널 (bash / zsh / PowerShell)

로컬 저장소 만들고 첫 커밋

git의 기본 흐름(init → add → commit)을 직접 수행하고 이력을 확인할 수 있다

[ ] git init 완료
[ ] 파일 생성 → git add → git commit 3회 반복
[ ] .gitignore 작성
[ ] git log --oneline으로 이력 확인

GitHub 원격 저장소에 push하고 URL 제출

로컬 저장소를 GitHub에 연결하고 커밋 이력을 업로드할 수 있다

[ ] GitHub 계정 생성
[ ] 저장소 public으로 생성
[ ] git remote add origin [URL]
[ ] git push -u origin main
[ ] README.md 작성

learngitbranching 기본 완주 + 브랜치 실험

브랜치 생성·전환의 의미를 이해하고 learngitbranching Introduction Sequence를 완료한다

[ ] learngitbranching.js.org 접속
[ ] Introduction Sequence 1~4 완료
[ ] git branch로 새 브랜치 생성
[ ] git switch로 전환 후 커밋
[ ] git log --all --oneline으로 브랜치 이력 확인
제출 안내

개인 GitHub 저장소 URL을 LMS 과제 제출 창에 입력한다. 저장소는 public으로 설정하고 README.md가 포함되어 있어야 한다. 커밋이 최소 3회 이상 있어야 제출 인정이다.

다음 수업 연결

오늘 만든 GitHub 저장소에 실습 파일을 커밋하며 관리하는 흐름이 이어진다. git add / commit / push가 매일 반복되므로 오늘 익힌 흐름이 곧 기본 습관이 된다.
