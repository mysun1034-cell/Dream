공개

지식 목표

비지도 학습과 지도 학습의 차이를 레이블 유무로 설명할 수 있다
- K-Means의 4단계(초기화→배정→중심이동→반복 수렴)와 Inertia 비용 함수를 설명할 수 있다
- 엘보우 기법으로 최적 K를 선택하고, 꺾임이 불명확할 때 도메인 기반으로 결정하는 이유를 설명할 수 있다
- PCA가 분산을 최대화하는 방향으로 차원을 축소하며, explained_variance_ratio_로 정보 보존량을 정량화할 수 있다
- K-Means 거리 기반 이상 탐지의 원리와 임계값 선택의 trade-off를 설명할 수 있다

기능 목표

`KMeans`로 과일 이미지를 군집화하고 `labels_`, `cluster_centers_`, `inertia_`를 코드로 확인할 수 있다
- `make_blobs`로 2D 데이터를 생성해 K-Means 수렴 과정을 산점도로 시각화할 수 있다
- `PCA(n_components=50)`으로 10,000차원을 압축하고, 원본 대비 LR 학습 시간을 비교할 수 있다
- `PCA(n_components=2)`로 2D 축소 후 K-Means 결과를 산점도로 시각화할 수 있다
- `km.transform(X).min(axis=1)`로 이상치 점수를 계산하고 퍼센타일 임계값으로 이상치를 탐지할 수 있다

산출물 목표

과일 데이터 K-Means 군집화 노트북 — 클러스터별 이미지 시각화 + 엘보우 그래프 포함
- PCA 압축 노트북 — explained_variance_ratio_ 그래프 + LR 학습 시간 비교 + 2D 산점도 포함
- Iris K-Means 검증 노트북 — confusion matrix + Adjusted Rand Score 계산 포함
