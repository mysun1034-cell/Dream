공개

지식 목표

퍼셉트론의 계산 구조(가중합 → 활성화)를 설명하고, 가중치와 편향의 역할을 구분할 수 있다
- XOR 문제가 단층 퍼셉트론으로 풀리지 않는 이유를 선형 분리 불가 개념으로 설명할 수 있다
- 활성화 함수가 없으면 층을 아무리 쌓아도 선형 모델과 같다는 것을 수식으로 설명할 수 있다
- Sigmoid와 Softmax의 출력 범위와 사용 위치를 구분할 수 있다
- Keras Sequential 모델의 5단계 패턴(정의·컴파일·학습·평가·요약)을 설명할 수 있다

기능 목표

`numpy`로 `perceptron()` 함수를 직접 구현하고 AND/OR/XOR 게이트를 코드로 검증할 수 있다
- `keras.Sequential`, `Input`, `Dense`로 단층 분류 모델을 구성하고 `model.summary()`로 파라미터 수를 확인할 수 있다
- sklearn digits 데이터에서 LogReg(ML)과 Dense 단층(DL)을 학습하고 결과를 비교·해석할 수 있다
- Fashion MNIST 데이터를 정규화·reshape 후 Keras 모델로 학습하고 `val_accuracy ≥ 0.84`를 달성할 수 있다

산출물 목표

퍼셉트론 구현 노트북 — `perceptron()` 함수 + AND/OR/XOR 진리표 코드 출력 포함
- Fashion MNIST 단층 분류 노트북 — model.summary() + val_accuracy 기록

/255.0 정규화 적용
reshape(-1, 784) 적용
train_test_split(test_size=0.2, random_state=42)
Dense(10, activation='softmax')
sparse_categorical_crossentropy

Iris MLP — 단층 vs 2층 성능 비교

Iris 데이터에 단층과 2층 MLP를 모두 적용하고, 성능 차이와 파라미터 수 차이를 비교 해석한다

StandardScaler 표준화 적용
단층: Dense(3, 'softmax')
2층: Dense(8, 'sigmoid') → Dense(3, 'softmax')

은닉층 깊이·너비에 따른 성능 변화를 실험표로 정리하고, "파라미터 많을수록 항상 좋은가?"에 답한다
