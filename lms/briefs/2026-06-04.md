공개

지식 목표

역전파(Backpropagation)의 흐름 — "오차가 출력층에서 입력층 방향으로 전파되며 각 가중치의 기여도를 계산" — 을 연쇄 법칙 흐름도 수준에서 설명할 수 있다
- Vanishing Gradient가 왜 발생하는지(Sigmoid 도함수 최대 0.25 × 층 수만큼 곱해짐)를 설명하고, ReLU가 이를 해결하는 이유를 말할 수 있다
- 활성화 함수 선택 기준(은닉층→ReLU, 출력층→문제 유형별)을 설명할 수 있다
- SGD와 Adam의 차이(고정 lr vs Momentum + 적응적 lr)를 설명할 수 있다

기능 목표

keras.Sequential + Flatten + Dense(relu) + Dense(softmax) 구조로 2층 분류 모델을 구성할 수 있다
- model.compile(optimizer='adam', ...) 으로 Adam 옵티마이저를 적용하고 val_accuracy 0.8723을 달성할 수 있다
- keras.optimizers.SGD(learning_rate=...), SGD(momentum=...) 코드로 옵티마이저 파라미터를 직접 조정할 수 있다
- 동일 모델에 여러 옵티마이저를 적용해 결과를 비교하는 실험을 설계할 수 있다

산출물 목표

심층 신경망 노트북 — 07-2 전체 재현, val_accuracy 0.8723 기록
- 옵티마이저 비교 실험 노트북 — SGD(기본) / SGD(lr=0.1) / Adam 결과표

07-2 재현 — 2층 ReLU + Adam 심층 신경망

enable_op_determinism() 포함

SGD vs Adam 옵티마이저 비교 실험

동일한 ReLU 2층 모델에 SGD(기본) / SGD(lr=0.1) / Adam 세 가지 옵티마이저를 적용해 val_accuracy를 비교하고, Adam이 왜 기본값이 됐는지 설명한다

make_model()로 매번 초기화된 새 모델 사용
keras.utils.set_random_seed(42) 각 반복마다 적용
verbose=0으로 진행 상황 숨김
model.evaluate()로 val_accuracy 측정

Learning Rate 조정 + CIFAR-10으로 Dense 한계 체험

Adam learning_rate 조정 실험으로 학습률의 영향을 관찰하고, CIFAR-10에 Dense 모델을 적용해 CNN 필요성을 직접 체감한다

CIFAR-10: cifar_ytrain.reshape(-1) 레이블 1D 변환
CIFAR-10 입력 shape: (32, 32, 3) — RGB 3채널 확인

Dense(100) params = 3,072×100 + 100 = 307,300
