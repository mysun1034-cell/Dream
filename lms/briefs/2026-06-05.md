공개

지식 목표

학습 곡선(train loss vs val loss)을 보고 과적합·과소적합 상태를 진단하고 해결 방향을 제시할 수 있다
- Dropout이 과적합을 줄이는 원리("랜덤 뉴런 비활성 → 과의존 방지, Inverted Dropout으로 기댓값 유지")를 설명할 수 있다
- EarlyStopping이 Dropout과 함께 정규화 역할을 하는 이유를 설명할 수 있다
- ModelCheckpoint와 EarlyStopping을 같이 쓰는 이유(디스크 저장 vs 메모리 복원)를 구분할 수 있다

기능 목표

`model_fn(a_layer=None)` 팩토리 패턴으로 실험마다 새 모델을 생성할 수 있다
- `model.fit(validation_data=...)` + `history.history`로 학습 곡선을 시각화할 수 있다
- `Dropout(0.3)` 레이어를 모델에 추가하고, `model.summary()`에서 params=0 임을 확인할 수 있다
- `ModelCheckpoint(save_best_only=True)` + `EarlyStopping(patience=2, restore_best_weights=True)` 콜백을 `fit(callbacks=[...])`에 연결할 수 있다
- `model.save()` / `keras.models.load_model()` 로 모델을 저장·복원하고 `evaluate()`를 실행할 수 있다
- 교재 07-3을 재현해 val_accuracy ≥ 0.8853을 달성할 수 있다
