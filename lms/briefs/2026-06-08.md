공개

지식 목표

합성곱(Convolution) 연산을 "필터 슬라이딩"으로 직관적으로 설명하고, 출력 feature map의 크기를 Padding·Stride 수식으로 직접 계산할 수 있다
- MaxPooling2D가 공간 크기를 줄이는 이유와 위치 불변성 효과를 설명할 수 있다
- Conv2D(32, kernel=3)의 파라미터 수 320개를 직접 계산하고, Dense 모델과 비교해 파라미터 공유(weight sharing)의 효율성을 설명할 수 있다
- 4D 텐서 `(batch, H, W, channels)`의 개념을 이해하고, `reshape(-1, 28, 28, 1)`이 필요한 이유를 설명할 수 있다

기능 목표

Fashion MNIST 데이터를 `reshape(-1, 28, 28, 1)`로 4D 텐서로 변환할 수 있다
- Conv2D + MaxPooling2D 블록을 Keras Sequential로 구성하고 `model.summary()`에서 각 층의 output shape와 파라미터 수를 확인할 수 있다
- `jit_compile=False`가 필요한 상황을 이해하고 적용할 수 있다
- ModelCheckpoint + EarlyStopping 콜백을 CNN 모델에 연결해 교재 08-2를 재현하고 val_accuracy ≥ 0.91을 달성할 수 있다
- CIFAR-10 데이터셋을 로드하고 3채널 입력으로 동일한 CNN 구조를 적용할 수 있다 (CHALLENGE)

산출물 목표

08-2 재현 노트북 — Conv→Pool×2 + Dense + Dropout 구조, val_accuracy ≥ 0.91
- 필터 수 실험 노트북 — Conv2D(32) vs Conv2D(64) 파라미터 수·성능 비교표
