공개

지식 목표

학습된 Conv 필터(가중치)를 이미지로 시각화해 "1층은 에지, 깊은 층은 복잡한 패턴"을 직접 눈으로 확인하고, 학습 전후 가중치 분포 변화(std 0.085 → 0.227)의 의미를 설명할 수 있다
- 함수형 API(Functional API)로 중간 층의 출력을 추출하는 모델을 구성하고, Sequential 모델과의 차이(단일 출력 vs 중간 출력 접근 가능)를 설명할 수 있다
- 데이터 증강의 원리(기존 이미지 변형으로 다양성 확보)와 Keras inline 방식(`RandomFlip`·`RandomRotation`·`RandomZoom`)을 설명하고, 훈련 때만 적용되는 이유를 설명할 수 있다
- 전이학습(Transfer Learning)의 개념(사전학습 모델 재사용)과 Feature Extraction 방식(`base_model.trainable=False` + 새 헤드)을 설명하고, 밑바닥 학습 대비 장점을 말할 수 있다
- Fine-Tuning이 전이학습과 어떻게 다른지(상위 층 일부 해제 + 낮은 LR), Catastrophic Forgetting 방지를 위해 학습률을 낮추는 이유를 설명할 수 있다
- Object Detection이 이미지 분류와 근본적으로 다른 문제인 이유(출력 개수 가변, 위치 + 종류 동시 예측)를 설명하고, YOLO의 grid 기반 단일 forward pass 아이디어를 직관적으로 설명할 수 있다
- DL 5일(퍼셉트론→MLP→정규화→CNN→시각화·증강·전이→응용) 흐름을 한 장의 개념 맵으로 설명할 수 있다

기능 목표

`model.layers[0].weights[0].numpy()`로 Conv 필터를 추출하고, `imshow(vmin=-0.5, vmax=0.5)` 옵션을 포함한 2×16 그리드를 출력할 수 있다
- `keras.Model(model.inputs[0], model.layers[0].output)`로 함수형 API 모델을 만들고, `predict()`로 중간 특성 맵을 추출할 수 있다
- `train_input[0:1]`(shape `(1,28,28)`)과 `train_input[0]`(shape `(28,28)`)의 차이를 이해하고, 4D 텐서 `reshape(-1,28,28,1)`을 올바르게 적용할 수 있다
- `keras.Sequential([RandomFlip, RandomRotation, RandomZoom])`으로 증강 파이프라인을 만들고 기존 CNN 모델에 레이어로 삽입할 수 있다
- `MobileNetV2(include_top=False, weights='imagenet')`으로 사전학습 모델을 로드하고, `base_model.trainable=False` + `GlobalAveragePooling2D` + 새 Dense 헤드로 전이학습 모델을 구성할 수 있다
- 전이학습 모델을 Fine-Tuning할 때 `base_model.trainable=True` + 상위 층 선택 해제 + `Adam(learning_rate=1e-4)` 재컴파일 패턴을 코드로 구현할 수 있다
- `ultralytics.YOLO("yolo11n.pt")`로 사전학습 모델을 로드하고, `model.predict()` 결과에서 `result.boxes`를 순회해 클래스·확신도·좌표를 출력할 수 있다
