공개

지식 목표

train/test split이 왜 필요한지, stratify 옵션이 언제 필요한지 설명할 수 있다
- 분류·회귀 문제에서 각각 어떤 평가 지표를 쓰는지 구분할 수 있다
- 모델 성능이 낮을 때 가능한 원인을 3가지 이상 말할 수 있다
- 학습한 모델을 파일로 저장하는 방법을 안다

기능 목표

sklearn 또는 TensorFlow/Keras로 baseline 모델을 학습하고 평가 지표를 출력할 수 있다
- classification_report 또는 에포크별 accuracy를 노트북에 기록할 수 있다
- 모델 결과에 대한 해석을 마크다운 셀에 작성할 수 있다
- 모델 파일을 저장할 수 있다 (joblib.dump 또는 model.save())

산출물 목표

모델 학습 노트북 (`model_*.ipynb`) — train/test split·모델 학습·평가 지표·결과 해석 포함

Python (scikit-learn, TensorFlow, Keras, pandas, numpy)
Jupyter Notebook / VSCode / Google Colab
Notion (칸반 보드)
팀별 선택 데이터셋 (Day 2에서 EDA 완료)

마일스톤 3 — 1차 모델 완성

EDA 결과를 바탕으로 첫 번째 모델을 학습하고, 평가 지표와 결과 해석을 노트북에 기록한다

train/test 분리를 했다
baseline 모델을 1개 이상 학습했다
평가 지표를 기록했다
모델 결과를 해석했다
모델 성능이 낮더라도 이유를 설명할 수 있다

비교 모델 추가 + 모델 저장

baseline보다 성능이 좋은 모델을 추가로 시도하고, 내일 Streamlit 연결을 위해 모델 파일을 저장해둔다

비교 모델을 1개 추가했다
baseline과 비교 모델의 성능 수치를 나란히 기록했다
모델 파일을 저장했다 (joblib.dump 또는 model.save())
