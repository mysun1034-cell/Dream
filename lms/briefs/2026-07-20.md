지식 목표

프로젝트 전 과정(문제 정의→핵심 기능→기술 스택 근거→MVP 데모→한계)을 논리적 흐름으로 설명할 수 있고, 6개 평가기준이 증거가 있는 곳에서 채점됨을 이해한다 — 완성도·발표·AI 핵심성은 발표에서 라이브로, 협업 이력·코드 위생·Spring AI ≥2개 실제 매핑은 레포를 열어야 보인다. 동료 발표에서 AI가 핵심 가치인지와 기능↔Spring AI 매핑의 적절성을 평가할 수 있고, API 키가 코드에서 지워져도 git 이력에 남는다는 것과 그 확인 방법을 안다.

기능 목표

5일간(+버퍼) 만든 AI 서비스를 발표로 비전문가도 이해하게 압축 전달하고 MVP 한 흐름을 라이브 또는 캡처로 시연할 수 있다. 제출물 (레포 URL·README·Project Board·발표 자료+데모)을 발표 시작까지 확정하고, git 이력의 키 노출을 스스로 grep해 점검하며, 동료 발표에 구체적·건설적 피드백을 작성하고 프로젝트 개인 회고를 작성할 수 있다.
