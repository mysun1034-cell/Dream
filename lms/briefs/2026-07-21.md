공개

지식 목표

텐서가 무엇인지(다차원 배열 + GPU 이동 + 기울기 추적)와 인덱싱·dim=으로 축을 줄이는 방법, autograd가 계산 그래프를 기록해 backward()로 기울기를 자동 계산하는 원리, 기울기가 누적되므로 zero_grad()가 필요한 이유, 모델이 nn.Linear·활성화 함수·nn.Sequential·nn.Module로 쌓아 올려진 것이며 활성화 함수가 없으면 층을 쌓은 의미가 사라진다는 것, 그리고 Keras model.fit() 한 줄이 PyTorch에서 학습 루프 5단계(forward → loss → zero_grad → backward → step)에 해당한다는 것을 설명할 수 있다.

기능 목표

WSL2 + Ubuntu 환경을 구성하고 VSCode를 원격 연결한 뒤, uv로 Python 3.12 가상환경을 만들고 nvidia-smi의 CUDA 버전에 맞는 PyTorch 빌드를 선택해 설치하여 torch.cuda.is_available()을 검증할 수 있다. 텐서를 인덱싱하고 dim=으로 축을 줄여 argmax로 예측 클래스와 정확도를 구할 수 있다. nn.Linear 한 층에서 출발해 nn.Sequential과 nn.Module로 모델을 정의하고, 학습 루프 5단계를 직접 작성해 분류 모델을 학습시키며, DataLoader로 배치 공급을 구성할 수 있다.

산출물 목표

각자의 PC에서 동작하는 붓꽃(Iris) 품종 분류 모델 노트북을 완성한다. 전처리(표준화) → DataLoader → nn.Module 모델 → 학습 루프 5단계 → 평가까지 전 과정이 포함되며, 테스트 정확도와 손실 곡선을 확인한다.
