공개

지식 목표

GPT 계열 모델이 하는 일이 '지금까지의 문장을 보고 어휘 전체에 다음 토큰 확률을 매기는 것' 하나이며, 그 확률에서 무엇을 고를지는 모델이 아니라 사용자가 정한다는 것을 이해한다. 로짓과 확률의 차이, 고르기-이어붙이기-다시넣기 반복이 곧 생성이라는 구조, 매번 1등만 고르는 greedy가 결정적이기 때문에 반복 붕괴에 빠진다는 인과를 설명할 수 있다. temperature가 확률을 직접 바꾸는 것이 아니라 로짓 사이의 간격을 바꾼다는 것, top-k는 후보 개수를 고정하고 top-p는 담는 확률을 고정한다는 차이를 안다.

기능 목표

KoGPT2를 PreTrainedTokenizerFast로 올바르게 열고, 모델 출력에서 마지막 자리의 로짓을 꺼내 softmax로 확률을 만든 뒤 상위 후보를 읽어낸다. argmax와 torch.cat만으로 생성 반복문을 직접 작성하고 그 결과가 model.generate()와 같음을 확인한다. do_sample·temperature·top_k·top_p·repetition_penalty·num_beams를 한 번에 하나씩만 바꿔 가며 결과 차이를 비교하고, matplotlib으로 자신의 프롬프트에 대한 확률 분포와 온도별 분포 모양을 그린다. OpenAI API 키를 환경변수로 안전하게 다루고 chat.completions.create로 첫 호출을 성공시켜 usage로 토큰 사용량을 확인한다.

산출물 목표

학습자가 직접 고른 프롬프트에 대해 greedy·top-p·temperature 세 가지 디코딩 설정의 생성 결과를 나란히 비교한 표와, 어느 것이 가장 읽을 만했는지에 대한 판단 한 줄을 제출한다. 확률 분포 그래프(next_token.png)를 캡처 대신 제출할 수 있다.

Python 3.12 (기존 가상환경 .venv 그대로)
transformers (PreTrainedTokenizerFast · GPT2LMHeadModel · AutoConfig · model.generate)
PyTorch 2.13.0 (softmax · topk · sort · cumsum · argmax · cat · manual_seed — forward 몇 번이라 CPU로도 완결, GPU 있으면 사용)
matplotlib 3.11.1 (확률 분포 막대그래프 · 온도별 순위 곡선 — 한글 폰트 지정 포함)
openai (chat.completions.create · max_completion_tokens · usage)
VSCode 대화형 창 (# %% 셀 단위 실행)
외부 데이터셋 없음. 관찰 대상은 사전학습 모델 skt/kogpt2-base-v2(125M, cc-by-nc-sa-4.0 — 비상업이므로 프로젝트 결과물에는 사용 불가)이며, Day 4에서 받은 klue/bert-base와 gogamza/kobart-summarization은 config 대조에만 쓰여 캐시를 그대로 재사용한다. 오후에는 OpenAI gpt-5.4-nano를 API로 호출한다. 생성에 넣는 프롬프트는 전부 학습자가 직접 쓴 자기 문장이다.

내 프롬프트로 디코딩 옵션 3개 비교

직접 고른 문장으로 greedy·top-p·temperature 세 가지 생성 결과를 나란히 비교하고, 어느 것이 가장 읽을 만한지 판단한다.

프롬프트를 내 문장으로 바꿨는가?
같은 프롬프트로 세 설정을 모두 돌렸는가?
반복 붕괴가 보이는지 확인했는가?
말이 되는지, 재미있는지 두 기준으로 읽어 봤는가?

반복 붕괴를 만들고 푼다

greedy로 반복 붕괴를 일부러 유도한 뒤 repetition_penalty를 조금씩 올려 루프가 풀리는 값을 직접 찾는다.

한 번에 repetition_penalty 하나만 바꿨는가?
붕괴 전 결과를 먼저 남겨 두었는가?
값을 올릴수록 계속 좋아지는지 직접 확인했는가?

캡스톤 — 쓸 만한 결과물 하나 만들기

오늘 배운 디코딩 옵션을 조합해 스스로 쓸 만하다고 판단한 결과물 하나를 만들고, 그렇게 판단한 근거와 사용한 설정을 함께 남긴다.

옵션을 빠뜨리지 않고 적었는가?
다른 사람이 같은 설정으로 재현할 수 있는가?
여러 번 뽑아 보고 고른 것인가?
제출 안내

필수 제출물은 미션 1 하나다. 학습자가 직접 고른 프롬프트에 대해 greedy·top_p=0.92·temperature=1.3 세 결과가 나란히 나온 표를 캡처하거나 확률 분포 그래프 파일(next_token.png)을 제출하고, 함께 세 줄을 적는다 — 내 프롬프트, 제일 읽을 만했던 것, 그렇게 본 이유 한 줄. 미션 2와 3은 선택이며 열린 과제는 제출하지 않는다. OpenAI 첫 호출은 제출물이 아니라 다음 수업 준비 확인이므로 응답이 떴는지 그 자리에서 확인만 한다.
