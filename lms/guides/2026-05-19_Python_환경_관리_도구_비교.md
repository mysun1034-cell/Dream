Python 환경 관리 도구 비교

Python으로 개발할 때는 보통 세 가지가 필요합니다.

패키지를 설치한다.
프로젝트마다 독립된 환경을 만든다.
다른 사람도 같은 환경에서 실행할 수 있게 기록한다.

아래 도구들은 이 문제를 해결하기 위해 사용됩니다.

도구	쉽게 말하면	주로 하는 일	한계
pip	패키지 설치 도구	pandas, numpy 같은 라이브러리 설치	가상환경은 직접 만들 수 없음
venv	가상환경 생성 도구	프로젝트별 독립 공간 만들기	패키지 설치는 pip가 필요함
conda	큰 환경 관리자	Python, 패키지, 과학계산 환경까지 관리	비교적 무겁고 별도 생태계 느낌이 있음
poetry	프로젝트 관리 도구	패키지 설치, 버전 기록, 배포 관리	초보자에게는 흐름이 조금 복잡할 수 있음
uv	빠른 통합 관리 도구	프로젝트 생성, 가상환경, 패키지 설치, 실행을 한 흐름으로 관리	비교적 최근 도구라 예전 자료에는 잘 안 나올 수 있음
핵심만 정리하면
도구	기억할 포인트
pip	설치 담당
venv	가상환경 담당
conda	데이터 과학용 큰 환경 담당
poetry	Python 프로젝트 관리 담당
uv	위 작업들을 빠르고 단순하게 묶어주는 도구
도구별 비교
도구	한 줄 정의	주 역할	가상환경 관리	패키지 설치	프로젝트 의존성 기록	잠금 파일	Python 버전 관리	대표 명령
pip	Python 기본 패키지 설치 도구	패키지 설치	직접 하지 않음	가능	약함	기본 없음	불가	pip install pandas
venv	Python 내장 가상환경 도구	가상환경 생성	가능	불가	없음	없음	제한적	python -m venv .venv
conda	패키지 + 환경 관리 도구	데이터·과학계산 환경 관리	가능	가능	가능	제한적	가능	conda create -n myenv python=3.11
poetry	Python 프로젝트·의존성 관리 도구	패키지 프로젝트 관리	가능	가능	강함	가능	제한적	poetry add pandas
uv	빠른 Python 패키지·환경·프로젝트 관리 도구	현대적 Python 작업 흐름 통합	가능	가능	강함	가능	가능	uv add pandas
도구별 핵심 이해
도구	쉽게 말하면	장점	단점
pip	패키지 설치기	Python 생태계의 기본 설치 도구, 대부분의 문서에서 사용	가상환경, 프로젝트 구조, 잠금 파일 관리는 따로 해야 함
venv	프로젝트별 독립 방 만들기 도구	Python에 기본 포함, 별도 설치 필요 없음	패키지 설치와 의존성 기록은 직접 관리해야 함
conda	Python 포함 큰 개발 환경 관리자	Python뿐 아니라 C/C++ 기반 과학계산 패키지, CUDA, R 등도 관리 가능	무겁고, Python 표준 생태계와 약간 다른 흐름을 가짐
poetry	Python 프로젝트 포장·출판 관리자	pyproject.toml, 의존성 관리, 패키지 배포에 강함	초보자에게 명령 체계가 다소 많고, 속도 이슈를 느끼는 경우가 있음
uv	빠르고 단순한 차세대 Python 작업 관리자	빠름, 가상환경 자동 관리, pyproject.toml/uv.lock 기반 재현성 좋음	비교적 새 도구라 기존 자료는 아직 pip, venv, conda 중심인 경우가 많음
역할 기준 비교
하고 싶은 일	기존 방식	uv 방식
프로젝트 만들기	폴더 만들기 + 직접 설정	uv init
가상환경 만들기	python -m venv .venv	필요 시 uv가 자동 생성
패키지 설치	pip install pandas	uv add pandas
현재 환경에서 실행	가상환경 활성화 후 python main.py	uv run python main.py
패키지 목록 기록	requirements.txt 직접 관리	pyproject.toml, uv.lock 자동 관리
다른 사람이 같은 환경 만들기	pip install -r requirements.txt	uv sync
Jupyter 연결	가상환경 생성 후 커널 별도 등록	uv add --dev ipykernel 후 커널 등록
