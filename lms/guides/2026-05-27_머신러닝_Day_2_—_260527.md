## Step 1. StandardScaler — 스케일 맞추기

### 왜 필요한가?

k-NN은 거리로 이웃을 찾습니다. 길이(cm)와 무게(g)의 단위가 다르면 무게가 거리 계산을 압도합니다.

| 특성 | 범위

| 길이 | 8 ~ 44 cm

| 무게 | 6 ~ 1100 g

표준화로 모든 특성을 평균 0, 표준편차 1로 맞춥니다.

z = (x − 평균) / 표준편차

### 핵심 규칙

⚠️ Data Leakage 방지 규칙

fit_transform은 훈련 세트에만. 테스트 세트에는 transform만 사용.

from sklearn.preprocessing import StandardScaler

ss = StandardScaler()
train_scaled = ss.fit_transform(train_input) # fit + transform
test_scaled = ss.transform(test_input) # transform만! (fit 금지)

### 정규화 vs 표준화

| | StandardScaler | MinMaxScaler

| 공식 | z = (x − μ) / σ | x' = (x − min) / (max − min)

| 결과 범위 | 제한 없음 | 0 ~ 1

| 이상치에 | 덜 민감 | 민감

| 언제 | 거리 기반 모델, 선형 회귀 | 이미지, 범위 고정 필요 시

## Step 2. k-NN 회귀 (교재 Ch03-1)

### 분류 vs 회귀

| | k-NN 분류 | k-NN 회귀

| 이웃 3개 결과 | [도미, 도미, 빙어] | [300g, 260g, 300g]

| 예측 방법 | 다수결 | 평균

| 출력 | "도미" | 286.7g

import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsRegressor
from sklearn.metrics import mean_absolute_error

# 데이터 준비 (교재 농어 데이터)
train_input, test_input, train_target, test_target = train_test_split(
perch_length, perch_weight, random_state=42)

train_input = train_input.reshape(-1, 1) # 1D → 2D (필수!)
test_input = test_input.reshape(-1, 1)

knr = KNeighborsRegressor()
knr.fit(train_input, train_target)

print("test R²:", knr.score(test_input, test_target)) # 0.9928
print("MAE:", mean_absolute_error(test_target, knr.predict(test_input))) # 약 19g

### R² (결정 계수) 해석

| 값 | 의미

| 1.0 | 완벽한 예측

| 0.0 | 평균을 항상 예측하는 것과 동일

| < 0 | 평균보다도 못한 모델 (오류 아님)

🔎 k-NN의 한계 — 외삽 불가

훈련 데이터 범위(최대 44cm)를 벗어난 50cm, 100cm 예측이 동일하게 나옴 → 가장 가까운 이웃이 같기 때문

## Step 3. 선형 회귀 + MSE + 경사 하강법 (교재 Ch03-2)

### 선형 회귀 코드

from sklearn.linear_model import LinearRegression

lr = LinearRegression()
lr.fit(train_input, train_target)

print(lr.coef_) # [39.02] ← 길이 1cm 증가 = 무게 39g 증가
print(lr.intercept_) # -709.02
print(lr.predict([[50]])) # [1241.84]

print("train R²:", lr.score(train_input, train_target)) # 0.9398
print("test R²:", lr.score(test_input, test_target)) # 0.8248

### MSE — 손실 함수

MSE = (1/n) × Σ(예측값 − 실제값)²

선형 회귀 학습 = MSE를 최소화하는 w, b를 찾는 것.

오차를 제곱하는 이유: 음수·양수가 상쇄되지 않도록 + 큰 오차에 더 큰 패널티.

### 경사 하강법 (Gradient Descent)

U자형 손실 함수에서 최솟값을 향해 한 발씩 이동합니다.

w ← w − α × ∂J/∂w

b ← b − α × ∂J/∂b

α (학습률): 너무 크면 발산, 너무 작으면 너무 느림

💡 scikit-learn의 LinearRegression()은 정규 방정식으로 한 번에 최적해를 구합니다. 경사 하강법은 Day 3 SGD에서 다시 등장합니다.

## Step 4. 다항 회귀 + 과적합 체험 (교재 Ch03-2, 03-3)

### 2차 방정식으로 곡선 맞추기

# x → [x², x]
train_poly = np.column_stack((train_input ** 2, train_input))
test_poly = np.column_stack((test_input ** 2, test_input))

lr2 = LinearRegression()
lr2.fit(train_poly, train_target)
print("train R²:", lr2.score(train_poly, train_target)) # 0.9707
print("test R²:", lr2.score(test_poly, test_target)) # 0.9776 ← 선형보다 향상!

### PolynomialFeatures 활용 (3개 특성 → 9개)

import pandas as pd
from sklearn.preprocessing import PolynomialFeatures

perch_full = pd.read_csv('https://bit.ly/perch_csv_data')
train_i, test_i, train_t, test_t = train_test_split(perch_full, perch_weight, random_state=42)

poly = PolynomialFeatures(include_bias=False)
poly.fit(train_i)
train_poly = poly.transform(train_i)
test_poly = poly.transform(test_i) # test에는 transform만!

print(train_poly.shape) # (42, 9)

### 과적합 체험 — degree=5

poly5 = PolynomialFeatures(degree=5, include_bias=False)
poly5.fit(train_i)
train_poly5 = poly5.transform(train_i)
test_poly5 = poly5.transform(test_i)
print(train_poly5.shape) # (42, 55)

lr.fit(train_poly5, train_t)
print("train R²:", lr.score(train_poly5, train_t)) # 1.0000 ← 과적합!
print("test R²:", lr.score(test_poly5, test_t)) # -144.4 ← 폭망!

### 학습 곡선 요약

| degree | 특성 수 | train R² | test R² | 진단

| 1 (선형) | 3 | 0.94 | 0.82 | 과소적합

| 2 | 9 | 0.99 | 0.97 | 적절

| 5 | 55 | 1.00 | -144 | 심각한 과적합

## Step 5. Ridge / Lasso — 규제로 과적합 억제 (교재 Ch03-3)

### 규제란?

손실 함수에 계수(w) 페널티를 추가해 모델이 너무 복잡해지는 것을 억제합니다.

Ridge 손실 = MSE + α × Σ(w²) ← L2 규제

Lasso 손실 = MSE + α × Σ|w| ← L1 규제

### 하이퍼파라미터 vs 파라미터

| | 예시 | 누가 결정?

| 파라미터 | 선형 회귀의 w, b | 모델이 데이터에서 학습

| 하이퍼파라미터 | alpha, n_neighbors | 사람이 직접 설정

### 스케일링 후 Ridge 적용

from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import Ridge

ss = StandardScaler()
train_scaled = ss.fit_transform(train_poly5)
test_scaled = ss.transform(test_poly5)

ridge = Ridge(alpha=0.1)
ridge.fit(train_scaled, train_t)
print("train R²:", ridge.score(train_scaled, train_t)) # 0.9904
print("test R²:", ridge.score(test_scaled, test_t)) # 0.9828 ← -144에서 회복!

### alpha 탐색 그래프

import matplotlib.pyplot as plt

train_score, test_score = [], []
alpha_list = [0.001, 0.01, 0.1, 1, 10, 100]

for alpha in alpha_list:
ridge = Ridge(alpha=alpha)
ridge.fit(train_scaled, train_t)
train_score.append(ridge.score(train_scaled, train_t))
test_score.append(ridge.score(test_scaled, test_t))

plt.plot(alpha_list, train_score, label='train')
plt.plot(alpha_list, test_score, label='test')
plt.xscale('log')
plt.xlabel('alpha')
plt.ylabel('R²')
plt.legend()
plt.show()

### Lasso 실습

from sklearn.linear_model import Lasso

lasso = Lasso(alpha=1, max_iter=10000)
lasso.fit(train_scaled, train_t)
print("train R²:", lasso.score(train_scaled, train_t)) # 0.9898
print("test R²:", lasso.score(test_scaled, test_t)) # 0.9801
print("0인 계수 수:", np.sum(lasso.coef_ == 0)) # 40~47 (자동 특성 선택)

### Ridge vs Lasso 비교

| | Ridge (L2) | Lasso (L1)

| 계수 동작 | 작게 만들지만 0이 되지 않음 | 불필요한 계수를 0으로 만듦

| 특성 선택 | 없음 | 자동 특성 선택 효과

| 선호 상황 | 모든 특성이 어느 정도 유효 | 불필요 특성이 많을 것 같을 때

## 오늘의 핵심 용어 13개

| 용어 | 한 줄 정의

| 회귀 (Regression) | 연속적인 숫자를 예측하는 지도학습

| R² (결정 계수) | 모델이 데이터 분산을 얼마나 설명하는가 (1이 완벽)

| MSE | 예측값과 실제값 차이의 제곱 평균

| 경사 하강법 | 기울기 반대 방향으로 파라미터를 조금씩 업데이트

| 학습률 (α) | 경사 하강법에서 한 번에 이동하는 크기

| 과적합 (Overfitting) | train 성능은 높지만 test 성능이 낮은 상태

| 과소적합 (Underfitting) | train과 test 둘 다 성능이 낮은 상태

| 규제 (Regularization) | 모델 복잡도에 페널티를 줘서 과적합을 억제

| Ridge | L2 규제. 계수 제곱합에 페널티

| Lasso | L1 규제. 계수 절댓값 합에 페널티. 자동 특성 선택

| 하이퍼파라미터 | 사람이 직접 설정하는 값 (alpha, n_neighbors 등)

| 특성 공학 | 기존 특성을 조합해 새로운 특성을 만드는 과정

| Data Leakage | 테스트 데이터 정보가 훈련에 새어들어가는 현상

## 흔한 오류 대처

| 오류 | 원인 | 해결

| ValueError: Expected 2D array | reshape 누락 | train_input.reshape(-1, 1)

| AttributeError: has no attribute 'mean_' | fit 없이 transform | ss.fit_transform(train_input) 먼저

| ConvergenceWarning (Lasso) | 반복 횟수 부족 | Lasso(max_iter=10000)

| R² 음수 | 오류 아님 | 과적합 확인 후 규제 적용

| URL 연결 실패 | 오프라인 환경 | CSV 로컬 저장본 사용
