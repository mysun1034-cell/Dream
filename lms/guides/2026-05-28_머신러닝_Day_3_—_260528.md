## Step 1. LogisticRegression — 확률로 분류하기

### k-NN 확률의 한계

k-NN(n_neighbors=3)의 확률은 0/3, 1/3, 2/3, 3/3 — 딱 4가지 값만 가능합니다. 실제 세계 확률은 0.73, 0.18처럼 연속적인 값이 필요합니다.

### 로지스틱 회귀의 동작 원리

입력 x

→

선형 결합
z = w·x + b

→

Sigmoid
σ(z) → 0~1

→

임계값 0.5
클래스 결정

내부 구조는 선형 회귀와 같습니다 — 마지막에 Sigmoid를 거쳐 확률로 변환합니다.

### Sigmoid 함수

σ(z) = 1 / (1 + e⁻ᶻ)

z → −∞ → σ(z) → 0

z = 0 → σ(z) = 0.5 ← 결정 경계

z → +∞ → σ(z) → 1

### 결정 경계 (Decision Boundary)

z = w·x + b = 0 인 지점에서 σ(0) = 0.5 — 이 선이 결정 경계입니다.

| z 값 | 확률 | 예측

| z > 0 | > 0.5 | 클래스 1

| z = 0 | = 0.5 | 결정 경계

| z < 0 | < 0.5 | 클래스 0

LogisticRegression의 결정 경계는 항상 직선(선형)입니다.

### 이진 분류 코드 — 도미 vs 빙어

lr = LogisticRegression()
lr.fit(train_bream_smelt, target_bream_smelt)

# classes_ 순서 반드시 확인 — 알파벳 순 정렬!
print(lr.classes_) # ['Bream' 'Smelt']
print(lr.predict_proba(...)) # [Bream 확률, Smelt 확률]

# Sigmoid 직접 검증
from scipy.special import expit
z = lr.decision_function(train_bream_smelt[:3])
print(expit(z)) # predict_proba 결과와 일치!

⚠️ classes_ 순서는 알파벳 순입니다. predict_proba 열 순서를 classes_ 없이 해석하면 클래스가 뒤바뀝니다.

### 다중 분류 — 7종 생선 (Softmax)

P(k) = e^(zk) / Σe^(zi) → 7개 확률의 합 = 1

lr = LogisticRegression(C=20, max_iter=1000)
lr.fit(train_scaled, train_target)

# predict_proba를 DataFrame으로
proba_df = pd.DataFrame(
lr.predict_proba(test_scaled[:10]).round(3),
columns=lr.classes_
)
print(proba_df.idxmax(axis=1)) # 최고 확률 종

### C 파라미터 — Ridge alpha와 반대!

| 모델 | 파라미터 | 방향

| Ridge | alpha ↑ | 규제 강해짐

| LogisticRegression | C ↑ | 규제 약해짐

Ridge: alpha↑ = 규제 강 | Logistic: C↑ = 규제 약 → 방향이 반대!

## Step 2. 평가지표 — 정확도의 함정을 넘어서

### 정확도만으로는 부족한 이유

| 모델 | 정확도 | 생존자 찾음

| 무조건 사망 예측 | 61.6% | 0명 (Recall=0)

| LogisticRegression | 79.7% | 일부 찾음

불균형 데이터에서 정확도만 보면 "무조건 다수 클래스 예측" 모델을 좋다고 착각할 수 있습니다.

### Confusion Matrix

| | 예측 양성(1) | 예측 음성(0)

| 실제 양성(1) | TP ✅ | FN ⚠ 놓침 (Type II)

| 실제 음성(0) | FP 과잉경보 (Type I) | TN ✅

FN (Type II) = 암 환자를 놓치는 것 → 의료에서 가장 위험한 오류

from sklearn.metrics import confusion_matrix
cm = confusion_matrix(y_test, y_pred)
# cm[0,0]=TN, cm[0,1]=FP
# cm[1,0]=FN, cm[1,1]=TP

### Precision · Recall · F1

Precision = TP / (TP + FP) → 양성 예측 중 실제 양성

Recall = TP / (TP + FN) → 실제 양성 중 찾아낸 비율

F1 = 2 × P × R / (P + R) → 조화평균

#### 임계값 트레이드오프

| 임계값 | Precision | Recall

| 높임 (↑) | ↑ 올라감 | ↓ 내려감

| 낮춤 (↓) | ↓ 내려감 | ↑ 올라감

#### 도메인별 중요 지표

| 도메인 | 중요 지표 | 이유

| 암 진단 | Recall | 환자를 놓치면 치명적

| 스팸 필터 | Precision | 정상 메일 차단이 더 불편

| 법원 판결 | Precision | 무고한 유죄를 최소화

from sklearn.metrics import classification_report
print(classification_report(y_test, y_pred,
target_names=['사망(0)', '생존(1)']))

### ROC-AUC

TPR = Recall = TP / (TP + FN)

FPR = FP / (FP + TN)

AUC = 1.0 → 완벽한 분류기

AUC = 0.5 → 랜덤 (쓸모없음)

from sklearn.metrics import roc_auc_score
y_prob = lr.predict_proba(X_test)[:, 1] # 양성(1) 확률
print("AUC:", roc_auc_score(y_test, y_prob).round(3))

## Step 3. bias/variance 진단 프레임워크

| 패턴 | train | test | 진단 | 해결 방향

| High Bias | 낮음 | 낮음 | 과소적합 | 복잡도 높이기, 특성 추가

| High Variance | 높음 | 낮음 | 과적합 | 데이터 추가, 규제 증가

| 적절한 피팅 ✅ | 높음 | 높음 | 좋은 일반화 | 유지

이 진단표는 Day 4(결정 트리), Day 5(앙상블)에서도 동일하게 사용합니다.

## Step 4. SGDClassifier — 에포크 그래프 + 조기 종료

### fit() vs partial_fit()

| 메서드 | 동작

| fit() | 매번 이전 학습 리셋

| partial_fit() | 이전 학습 누적 — 에포크 반복에 사용

sc = SGDClassifier(loss='log_loss', random_state=42)
train_score, test_score = [], []
classes = np.unique(train_target) # 전체 클래스 목록

for _ in range(300):
# 첫 호출에서 classes= 반드시 전달!
sc.partial_fit(train_scaled, train_target, classes=classes)
train_score.append(sc.score(train_scaled, train_target))
test_score.append(sc.score(test_scaled, test_target))

### 그래프 읽는 방법

epoch ≈ 25: test 정확도 최고점 → 조기 종료 적정 지점

epoch 25 → 300: train 계속 오름, test 정체 → High Variance 시작

### 흔한 오류

| 오류 | 원인 | 해결

| ValueError: classes must be passed | 첫 partial_fit에 classes= 누락 | classes=np.unique(train_target) 추가

| 에포크 그래프가 이상하게 진동 | for 루프 안에 fit() 사용 | partial_fit()으로 변경

## 용어 정리

| 용어 | 한 줄 정의

| Sigmoid | z를 0~1 확률로 압축하는 S자 함수

| Softmax | k개 클래스의 z값을 합=1인 확률 분포로 변환

| 결정 경계 | z=0인 지점 (P=0.5), 클래스를 나누는 선

| Confusion Matrix | TP/TN/FP/FN으로 예측 오류를 세분화한 표

| Precision | 양성 예측 중 실제 양성 비율 (FP 관련)

| Recall | 실제 양성 중 찾아낸 비율 (FN 관련)

| F1 Score | Precision과 Recall의 조화평균

| ROC-AUC | 임계값 변화에 따른 TPR vs FPR 곡선 아래 면적

| High Bias | train/test 둘 다 낮음 — 과소적합

| High Variance | train 높고 test 낮음 — 과적합

| partial_fit | 이전 학습을 유지하며 누적 학습하는 메서드

| epoch | 전체 훈련 데이터를 1회 순회하는 것

| 조기 종료 | test 성능이 최고점을 찍은 에포크에서 학습 중단
