## Part 1. 퍼셉트론 — numpy로 직접 만들기

### 퍼셉트론 구조

입력 x₁, x₂

→

z = w·x + b

→

a = σ(z)

→

예측 (0 또는 1)

- 가중치(w): 입력의 중요도 — "이 정보가 얼마나 중요한가"

- 편향(b): 뉴런이 얼마나 쉽게 켜지는지 조절

- Sigmoid σ(z): z를 (0,1) 확률로 변환

💡 면접관 비유: 학점(x₁)·영어(x₂)·경력(x₃)에 가중치를 주고 합산. 편향은 "이 회사가 얼마나 까다로운지". 합산이 임계값을 넘으면 합격(출력=1).

### 1 np.dot으로 가중합

import numpy as np

x = np.array([1, 0])
w = np.array([0.6, 0.4])
b = -0.5

z = np.dot(w, x) + b
print(f"z = {round(z, 4)}") # z = 0.1

### 2 Sigmoid 함수

σ(z)=11+e−z\sigma(z) = \frac{1}{1 + e^{-z}}σ(z)=1+e−z1​

def sigmoid(z):
return 1 / (1 + np.exp(-z))

for z_val in [-3, -1, 0, 1, 3]:
print(f" σ({z_val:+d}) = {sigmoid(z_val):.4f}")

σ(-3) = 0.0474 ← 0에 가까움
σ(-1) = 0.2689
σ(+0) = 0.5000 ← 경계선
σ(+1) = 0.7311
σ(+3) = 0.9526 ← 1에 가까움

### 3 perceptron() 함수

def perceptron(x, w, b, threshold=0.5):
z = np.dot(w, x) + b # 가중합
a = sigmoid(z) # 활성화
pred = int(a >= threshold) # 판단
return pred, a, z

pred, a, z = perceptron(np.array([1,0]), np.array([0.6,0.4]), -0.5)
print(f"z={round(z,3)}, σ(z)={round(a,3)}, 예측={pred}")
# z=0.1, σ(z)=0.525, 예측=1

### 4 AND 게이트 (w=[1,1], b=−1.5)

inputs = [(0,0), (0,1), (1,0), (1,1)]
targets = [ 0, 0, 0, 1 ]
w_and, b_and = np.array([1.0, 1.0]), -1.5

for (x1,x2), t in zip(inputs, targets):
pred, a, z = perceptron(np.array([x1,x2]), w_and, b_and)
print(f" ({x1},{x2}) z={z:+.1f} σ={a:.3f} 예측={pred} {'✓' if pred==t else '✗'}")

(0,0) z=-1.5 σ=0.182 예측=0 ✓
(0,1) z=-0.5 σ=0.378 예측=0 ✓
(1,0) z=-0.5 σ=0.378 예측=0 ✓
(1,1) z=+0.5 σ=0.622 예측=1 ✓

### 5 OR 게이트 — 편향만 b=−0.5로 변경

가중치(w)는 그대로, 편향(b) 하나만 −1.5 → −0.5로 바꾸니 AND → OR. 가중치·편향의 조합이 학습된 지식.

단층 퍼셉트론으로는 4/4 달성 불가! 결정 경계가 직선이라 XOR처럼 비선형으로 분리된 데이터를 구분할 수 없다.

해결: 층을 하나 더 → 비선형 경계 → 다층 퍼셉트론(MLP)

## Part 2. 다층 퍼셉트론(MLP) 구조

### 층의 역할

| 층 | 역할

| 입력층 | 데이터를 그대로 전달, 연산 없음

| 은닉층 | 중간 표현(feature) 자동 학습 — 피처 자동 발견

| 출력층 | 최종 예측 (분류: 각 클래스 확률)

### 활성화 함수가 없으면?

# 활성화 없이 2층:
# Layer 2: ŷ = W²(W¹x + b¹) + b² = (W²W¹)x + (W²b¹+b²) = Wx + b
# → 결국 선형 변환 하나와 동일!

층을 100개 쌓아도 선형 모델과 수학적으로 같다. 비선형 활성화 함수가 있어야 층이 의미를 가진다.

### 오늘 쓸 활성화 함수

| 함수 | 수식 | 출력 | 사용 위치

| Sigmoid | 11+e−z\frac{1}{1+e^{-z}}1+e−z1​ | (0, 1) | 이진 분류 출력층

| Softmax | ezk∑ezj\frac{e^{z_k}}{\sum e^{z_j}}∑ezj​ezk​​ | (0,1), 합=1 | 다중 분류 출력층 ← 오늘

| ReLU | max(0, z) | [0, ∞) | 은닉층 ← Day 2

### Softmax 확인

def softmax(z):
exp_z = np.exp(z)
return exp_z / exp_z.sum()

z = np.array([2.0, 1.0, 0.1])
print(softmax(z)) # [0.659 0.242 0.099]
print(softmax(z).sum()) # 1.0000 ← 항상 1

### Flatten이 필요한 이유

28×28 이미지 (2D) → (784,) 벡터 (1D)
Dense는 1D 입력만 받음
→ reshape(-1, 28*28) 또는 keras.layers.Flatten()

### 파라미터 수 계산

Dense(784 → 10): 784 × 10 + 10 = 7,850

가중치 행렬(784×10=7,840) + 편향 벡터(10) = 7,850개

## 핵심 용어

| 용어 | 한 줄 정의

| 퍼셉트론 | 가중합 + 편향 → 활성화 함수를 통과하는 인공 뉴런

| 가중치(w) | 입력의 중요도. 학습으로 업데이트됨

| 편향(b) | 뉴런이 얼마나 쉽게 활성화되는지 조절

| Sigmoid | (0,1)로 압축. 이진 분류 출력층

| Softmax | 합=1 확률 분포. 다중 분류 출력층

| 순전파 | 입력→은닉→출력 방향으로 계산

| 텐서 | 딥러닝의 다차원 배열. shape으로 표현

| Flatten | (28,28) → (784,) 1D로 펼침

| Dense | 이전 층과 완전연결된 레이어

| sparse_categorical_crossentropy | 정수 레이블 다중 분류 손실 함수

| epoch | 전체 훈련 데이터 1회 통과

| batch | 한 번에 처리하는 샘플 묶음 (기본 32개)
