## Part 2. Vanishing Gradient

### Sigmoid 도함수 최대값 = 0.25

import numpy as np

def sigmoid_deriv(z):
s = 1 / (1 + np.exp(-z))
return s * (1 - s)

z_vals = np.linspace(-5, 5, 1000)
print(sigmoid_deriv(z_vals).max()) # 0.2500

### 층이 깊어질수록 기울기 소멸

| 은닉층 수 | 기울기 크기 (최적) | 실제 평균

| 1층 | 0.25 | ~0.1

| 2층 | 0.0625 | ~0.01

| 3층 | 0.0156 | ~0.001

| 5층 | 0.001 | ~0.00001

⚠️ 오늘 2층 Sigmoid 모델은 학습됨(Epoch 5 acc=0.8759). VG는 10층+ 깊은 네트워크에서 치명적.

## Part 3. ReLU 은닉층 기본값

g(z)=max⁡(0,z)g(z) = \max(0, z)g(z)=max(0,z)

def relu(z):
return max(0, z)

for z in [-3, -1, 0, 1, 3]:
print(f" relu({z:+d}) = {relu(z)}")
# relu(-3) = 0 relu(-1) = 0 relu(+0) = 0 relu(+1) = 1 relu(+3) = 3

| 항목 | Sigmoid | ReLU

| 도함수 최대 | 0.25 | 1.0

| VG 문제 | 심각 (깊을수록) | 없음

| 계산 속도 | exp() 필요 | 비교만 (빠름)

| 은닉층 적합 | ✗ | ✓

### 활성화 함수 선택 가이드

| 위치 | 문제 유형 | 권장

| 은닉층 | 모든 경우 | ReLU

| 출력층 | 이진 분류 | Sigmoid

| 출력층 | 다중 분류 | Softmax

| 출력층 | 회귀 | Linear (없음)

Dead ReLU란?

입력이 항상 음수인 뉴런 → 출력 항상 0 → 기울기 항상 0 → 가중치 영구 업데이트 안 됨. 해결책(LeakyReLU 등)은 Day 5에서 다룸.

## Part 6. ReLU 교체 + Flatten 내장

⚠️ 데이터 재로딩 필요: B-5에서 reshape(-1,784)로 변환된 데이터는 (48000,784). 새 모델은 Input(28,28) 받으므로 2D 원본 재로딩.

(train_input, train_target), _ = keras.datasets.fashion_mnist.load_data()
train_scaled = train_input / 255.0 # reshape 없이 (60000,28,28)
train_scaled, val_scaled, train_target, val_target = train_test_split(
train_scaled, train_target, test_size=0.2, random_state=42)

model = keras.Sequential()
model.add(keras.layers.Input(shape=(28, 28)))
model.add(keras.layers.Flatten()) # params = 0 !
model.add(keras.layers.Dense(100, activation='relu')) # 은닉층 ReLU
model.add(keras.layers.Dense(10, activation='softmax')) # 출력층

model.compile(loss='sparse_categorical_crossentropy', metrics=['accuracy'])
model.fit(train_scaled, train_target, epochs=5)
model.evaluate(val_scaled, val_target)

기대 출력: val_accuracy = 0.8652 (rmsprop 기본값)

Flatten params=0: shape 변환만, 학습 파라미터 없음.

## Part 7. 옵티마이저

### SGD Stochastic = 미니배치

# 기본 (lr=0.01)
model.compile(optimizer='sgd', ...)

# 학습률 직접 설정
sgd = keras.optimizers.SGD(learning_rate=0.1)

Stochastic = 전체 데이터 대신 32개 미니배치로 기울기 계산 → 1 epoch = 1,500번 업데이트

### Adam 현재 사실상 기본값

model.compile(optimizer='adam',
loss='sparse_categorical_crossentropy',
metrics=['accuracy'])
model.fit(train_scaled, train_target, epochs=5)
model.evaluate(val_scaled, val_target)

| Adam의 두 가지 | 역할

| Momentum (1차 모멘트) | 이전 기울기 방향 기억 → 관성

| 적응적 lr (2차 모멘트) | 기울기 크면 lr↓, 작으면 lr↑

Adam 기대 출력: val_accuracy = 0.8723

## 핵심 용어 정리

| 용어 | 한 줄 정의

| 역전파 | Loss → 출력층 → 은닉층 방향으로 각 가중치 기여도 계산

| 연쇄 법칙 | 합성 함수 미분: ∂L∂W=∂L∂y^⋅∂y^∂W\frac{\partial L}{\partial W} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial W}∂W∂L​=∂y^​∂L​⋅∂W∂y^​​

| Vanishing Gradient | Sigmoid 도함수(max 0.25)가 층마다 곱해져 기울기 소멸

| ReLU | max(0,z) — 양수 기울기=1, VG 없음, 은닉층 기본값

| SGD | 32개 미니배치로 기울기 계산, 고정 학습률

| Momentum | 이전 업데이트 방향 기억(관성), SGD(momentum=0.9)

| Adam | Momentum + 적응적 lr 결합, 현재 사실상 기본 옵티마이저

| Learning Rate | 가중치 업데이트 보폭, W ← W - lr × gradient

| Flatten | (28,28) → (784,) 변환 레이어, 파라미터 없음

| enable_op_determinism | GPU 연산 순서 고정 → 완전한 재현성 보장
