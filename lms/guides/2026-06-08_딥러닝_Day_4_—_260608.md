## 1. Dense 모델의 한계

### Flatten이 버리는 것

28×28 이미지: Flatten 후:
┌──────────┐ [픽셀1, 픽셀2, ..., 픽셀784]
│ ○ × ○ │ →
│ ○ ○ × │ 위치 정보 사라짐
└──────────┘

- Dense는 모든 픽셀을 동등하게 연결 — "어떤 픽셀이 옆에 있는지" 모름

- 고양이 귀가 왼쪽 위에 있든 오른쪽 아래에 있든 Dense는 완전히 다른 입력으로 처리

### 파라미터 폭발

Dense(32, input=784) = 784 × 32 + 32 = 25,120 파라미터

필터(가중치) 수만큼 독립적인 가중치가 필요 — 같은 패턴도 위치마다 다시 학습해야 한다.

## 2. 합성곱 (Convolution)

직관: 작은 필터(돋보기)를 이미지 위에서 슬라이딩하며 "이 위치에 이 패턴이 있나?"를 계산한다.

연산 원리: 3×3 필터를 한 위치에 겹쳐서 원소별 곱셈 후 합산 → 하나의 값

이미지 구역: 필터: 결과:
3 0 1 1 0 -1
1 5 8 × 1 0 -1 → -5 (세로 에지 감지)
2 7 2 1 0 -1

특성 맵(Feature Map): 필터 하나를 이미지 전체에 적용한 결과 맵

### 파라미터 공유 (Weight Sharing)

Conv2D(32, kernel=3×3, input_channels=1):
(3×3×1 + 1) × 32 = 320 파라미터
→ 같은 필터가 이미지 전체에 공유 — 78배 효율

💡 핵심: 에지 탐지기는 이미지 어디서나 동일하게 동작한다. 같은 필터로 왼쪽 위의 에지와 오른쪽 아래의 에지를 모두 감지할 수 있다.

## 3. Padding · Stride

### Padding

| 종류 | 출력 크기 | 특징

| valid (no pad) | n - f + 1 | 경계 정보 손실, 크기 감소

| same (zero pad) | n | 입력과 동일 크기 유지

same padding: 경계에 0을 추가. P = (f-1)/2 → f=3이면 P=1

keras.layers.Conv2D(32, kernel_size=3, padding='same')
# 입력 28×28 → 출력 28×28 (크기 유지)

### Stride

필터 이동 간격. stride=1이면 한 칸씩, stride=2이면 두 칸씩.

출력 크기 = ⌊n+2P−fS⌋+1\left\lfloor \frac{n + 2P - f}{S} \right\rfloor + 1⌊Sn+2P−f​⌋+1

## 4. MaxPooling2D

Conv 이후 공간 크기를 절반으로 줄이는 연산. MaxPooling2D(2): 2×2 구역에서 최댓값만 추출

입력 4×4: 출력 2×2:
┌──┬──┬──┬──┐ ┌────┬────┐
│ 1│ 3│ 2│ 1│ │ 9 │ 2 │
├──┼──┼──┼──┤ → ├────┼────┤
│ 2│ 9│ 1│ 1│ │ 6 │ 3 │
├──┼──┼──┼──┤ └────┴────┘
│ 1│ 3│ 2│ 3│
├──┼──┼──┼──┤
│ 5│ 6│ 1│ 2│
└──┴──┴──┴──┘

| 역할 | 설명

| 크기 축소 | 연산량 감소

| 위치 불변성 | 패턴이 구역 내 어디 있든 최댓값이 대표

| params | = 0 (학습 파라미터 없음 — Dropout과 같음)

## 8. 핵심 용어 정리

| 용어 | 정의

| 합성곱(Convolution) | 필터를 이미지 위에 슬라이딩하며 특징을 추출하는 연산

| 필터/커널 | 학습되는 작은 가중치 배열 (예: 3×3). "이 패턴이 여기 있나?" 탐지기

| 특성 맵(Feature Map) | 필터 하나를 이미지 전체에 적용한 결과 맵

| Padding | 경계에 0을 추가해 출력 크기를 조절하는 방법

| same padding | 출력 H×W = 입력 H×W 유지

| valid padding | 패딩 없음, 출력 크기 줄어듦

| Stride | 필터 이동 간격 (기본값 1)

| MaxPooling2D | 2×2 구역 최댓값 추출 → 공간 크기 절반, params=0

| 위치 불변성 | 패턴 위치가 조금 달라도 같은 특징으로 인식하는 성질

| weight sharing | 같은 필터를 이미지 전체에 적용 → 파라미터 수 대폭 절감

| 4D 텐서 | (batch, H, W, channels) — Conv2D 입력 형태

| 공간 계층 구조 | 얕은 층: 에지 → 깊은 층: 복잡한 패턴 순서로 학습

| jit_compile=False | XLA 컴파일 비활성화 — MaxPooling + 재현성 설정 충돌 방지
