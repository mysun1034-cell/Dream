# 개인정보 정리 체크리스트

팀 편성 후 자리를 이동하기 전, 지금 사용 중인 PC에서 개인 정보를 정리해 주세요. 약 5분이면 됩니다.

진행률
0 / 11 완료

1

브라우저 — 가장 중요

Chrome · Edge · 기타 사용 브라우저 모두 처리

-

방문 기록·쿠키·캐시·비밀번호 삭제

Ctrl + Shift + Del → 기간: 전체 기간 선택

체크 항목: 인터넷 사용 기록 / 쿠키 / 캐시 / 비밀번호 및 로그인 데이터 / 양식 자동완성

-

브라우저 계정 로그아웃 (프로필 동기화 해제)

우측 상단 프로필 아이콘 클릭 → 로그아웃 및 동기화 해제 → 프로필 삭제

GitHub, Gmail 등 웹 로그인 상태도 함께 해제됨

-

GitHub 웹 로그아웃 확인

브라우저에서 github.com 열어 로그인 상태인지 확인 후 Sign out

비밀번호를 브라우저에 저장했다면 반드시 삭제하세요. 다음 사람이 내 계정으로 로그인할 수 있습니다.

2

파일 정리

다운로드 폴더 · 바탕화면 · 작업 폴더

-

내 파일 영구 삭제

다운로드 폴더·바탕화면에서 내 파일 선택 →
Shift + Delete (휴지통 없이 영구 삭제)

-

휴지통 비우기

바탕화면 휴지통 우클릭 → 휴지통 비우기

3

클립보드 기록 삭제

복사한 비밀번호·토큰이 남아 있을 수 있음

-

클립보드 기록 모두 지우기

Win + V → 클립보드 창 열기 → 모두 지우기 클릭

클립보드 기록 기능이 꺼져 있으면 이 단계는 패스

4

Git 설정 초기화

내 이름·이메일이 전역 설정에 남아 있으면 다음 사람 커밋에 내 정보가 표시됨

-

Git 전역 user 설정 삭제

# 터미널(PowerShell 또는 Git Bash)에서 실행

git config --global --unset user.name

git config --global --unset user.email

오류가 나도 설정값이 없는 것이니 정상입니다

-

설정 삭제 확인

git config --global user.name
# 아무것도 안 나오면 OK

git config --global user.email
# 아무것도 안 나오면 OK

5

앱 로그아웃

설치형 앱에서 내 계정이 열려 있는 경우

-

VSCode GitHub 계정 로그아웃

VSCode 좌하단 계정 아이콘(👤) 클릭 → 계정 이름 → Sign Out

-

카카오톡 / 디스코드 PC앱 로그아웃 (사용한 경우)

앱 설정 → 로그아웃. 사용하지 않았으면 패스

새 자리에서 GitHub 재로그인이 필요합니다. 브라우저에서 github.com → Sign in, 그리고 VSCode에서도 재인증하세요.
