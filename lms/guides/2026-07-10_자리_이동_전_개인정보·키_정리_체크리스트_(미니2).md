# 개인정보 · API 키 정리 체크리스트

팀 자리로 이동하기 전, 이 PC에서 내 계정·키·자격증명을 정리하세요. 이번엔 API 키가 가장 중요합니다. 약 7분.

이번 파트는 Spring AI(Gemini) 키를 다뤘습니다. 키가 .env·환경변수·IntelliJ 실행 구성에 남아 있으면 다음 사람이 내 키로 요금을 쓸 수 있습니다. 1번을 가장 먼저 하세요.

진행률
0 / 0 완료

1

🔑 API 키 · 시크릿 — 최우선

이번 파트에서 만진 Gemini/Google 키를 이 PC에서 지운다

-

프로젝트 폴더의 .env 파일 삭제

실습·팀 프로젝트 폴더의 .env, .env.local에 키가 있을 수 있음 → 파일 삭제(Shift + Delete)

-

application.yml / application-secret.yml에 하드코딩된 키 확인

키를 직접 적어 뒀다면 그 파일 삭제. (원칙은 ${GOOGLE_API_KEY} 환경변수 참조)

-

환경변수에 등록한 키 삭제

# Windows (PowerShell)

[Environment]::SetEnvironmentVariable("GOOGLE_API_KEY", $null, "User")

# 또는: 시스템 속성 → 환경 변수 → 사용자 변수에서 삭제

# macOS / Git Bash

# ~/.zshrc · ~/.bashrc 에 export 한 키 줄 삭제 후 저장

-

IntelliJ 실행 구성(Run Configuration)의 환경변수에 키 있으면 삭제

Run/Debug Configurations → 해당 구성 → Environment variables에 GOOGLE_API_KEY 등이 있으면 지우기

-

(사용했다면) AI CLI 키 파일 삭제

~/.config/io.datasette.llm/keys.json 등 도구에 저장한 키 파일

키가 이미 어딘가(커밋·화면공유 등)로 노출됐다면 삭제만으론 부족합니다 — 발급처(Google AI Studio)에서 그 키를 폐기·재발급하세요.

2

🌐 브라우저 계정 · 비밀번호

Chrome · Edge 등 사용한 브라우저 모두

-

방문 기록·쿠키·캐시·비밀번호 삭제

Ctrl + Shift + Del → 기간: 전체 기간 · 체크: 사용 기록 / 쿠키 / 캐시 / 비밀번호 및 로그인 데이터 / 양식 자동완성

-

브라우저 프로필 로그아웃 (동기화 해제)

우측 상단 프로필 → 로그아웃 및 동기화 해제 → 프로필 삭제

-

Google 계정 로그아웃 (Gemini / AI Studio 로그인분 포함)

google.com·aistudio.google.com에 로그인돼 있으면 Sign out. GitHub·Gmail 웹 로그인도 해제

브라우저에 저장한 비밀번호는 반드시 삭제하세요. 다음 사람이 내 계정으로 로그인할 수 있습니다.

3

🔐 Git 자격증명 · GitHub CLI

이름·이메일 + 저장된 GitHub 토큰까지

-

Git 전역 user 설정 삭제 + 확인

git config --global --unset user.name

git config --global --unset user.email

git config --global user.name # 아무것도 안 나오면 OK

오류가 나도 설정값이 없는 것이니 정상입니다

-

저장된 GitHub 자격증명(토큰) 삭제 — 이게 한걸음 더

Windows: 제어판 → 자격 증명 관리자 → Windows 자격 증명 → git:https://github.com 제거

macOS: 키체인 접근 → github.com 검색 → 항목 삭제

-

GitHub CLI 로그아웃 (사용했다면)

gh auth logout
# gh 미설치면 패스

4

💡 IntelliJ IDEA · VSCode

IDE에 연결된 계정 로그아웃

-

IntelliJ — GitHub 계정 제거

Settings(Ctrl + Alt + S) → Version Control → GitHub → 내 계정 선택 → –(제거)

-

IntelliJ — JetBrains 계정 로그아웃 (로그인했다면)

우측 상단 프로필 아이콘 → Log Out

-

VSCode — GitHub 계정 로그아웃 (사용했다면)

좌하단 계정 아이콘(👤) → 계정 이름 → Sign Out

5

🐳 앱 로그아웃

Docker · 메신저 등 설치형 앱

-

Docker Desktop 로그아웃 (DB·컨테이너 실습에 사용했다면)

Docker Desktop 우측 상단 계정 → Sign out

-

카카오톡 / 디스코드 PC앱 로그아웃 (사용했다면)

앱 설정 → 로그아웃. 사용하지 않았으면 패스

6

📁 파일 · 클립보드 정리

다운로드·바탕화면·복사 기록

-

내 파일 영구 삭제 + 휴지통 비우기

다운로드·바탕화면·작업 폴더에서 내 파일 선택 → Shift + Delete → 휴지통 비우기

-

클립보드 기록 모두 지우기

Win + V → 모두 지우기 (복사한 키·비밀번호가 남아 있을 수 있음). 기능이 꺼져 있으면 패스
