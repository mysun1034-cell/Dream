01API 계약 — 문서화 대상

POST /api/inquiries

"answer": "...", "createdAt": "2026-07-13T14:30:00" }

02책임 분리 — 레이어

[React] 사용자 입력 수신, API 요청, 로딩/오류 상태

[Service] 프롬프트 구성, AI 호출, 응답 가공, 저장 지시
[Spring AI/DB] ChatClient 통신, Repository CRUD

▸ 막힐 때 빠른 점검

- 앱이 안 뜬다 → javac -version(JDK 21?) · application.yml 탭 · 포트 8080

- 호출 500/401 → 키 재설정 후 앱 재시작, 키가 AIza… 형식(AQ.…는 무효)

- Unrecognized token 크래시 → 구조화 출력인데 평문 반환. 프롬프트 출력 형식 JSON 명시, .content()로 원문 먼저 확인

- 예외 설계 → 입력 누락 400 · AI 실패 500 + 트랜잭션 롤백(반쪽 저장 금지) · 키는 백엔드 환경변수
