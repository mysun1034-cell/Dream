03README = 실행 계약 (낯선 사람 기준)

## 실행 방법
### 백엔드
- 환경변수: GOOGLE_API_KEY=...(본인 키)
- 실행: ./gradlew bootRun # 포트 8080
### 프론트
- npm install && npm run dev # 포트 5173
## API 목록 / 사용 모델(gemini-3.1-flash-lite) / 제한

▸ 막힐 때 빠른 점검

- 재기동하면 빈 화면/에러 → DB 시드 없음 / 환경변수·키 누락. 재현 절차를 README에 고정

- 다른 PC·클린 클론에서 안 뜸 → 로컬 경로 하드코딩 / .env.example 없음

- 한 흐름만 자꾸 실패 → 5173·8080 둘 다 기동했나 · CORS 확인

- 2번째 기능 불안정 → 라이브에서 빼고 격리. 코드·README·캡처엔 남김

- "시간 남으니 하나 더" → ❌ 오후는 동결. 새 기능은 발표 후 확장으로

- 키를 코드에? → ❌ 코드·설정·git 이력에서 제거, 환경변수로

오늘 지킨 그 한 흐름이, 발표에서 심사자 앞에 그대로 다시 돈다.
