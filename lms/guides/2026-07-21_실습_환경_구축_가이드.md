# 실습 환경 구축 가이드 — PyTorch + WSL

이 문서 하나만 보고 처음부터 끝까지 환경을 만들 수 있게 썼습니다.
수업에서 함께 진행하지만, 집 PC에서 다시 만들 때도 이 문서를 그대로 따라오면 됩니다.
막히는 곳이 나오면 §8 문제 해결을 먼저 보세요.

## 0. 우리가 만들 환경

Windows
└─ WSL2 (윈도우 안의 리눅스)
└─ Ubuntu
└─ uv 가상환경 (Python 3.12)
└─ PyTorch ← 여기서 코드를 짭니다

전체 순서

- 그래픽카드 확인 (nvidia-smi)

- WSL2 + Ubuntu 설치

- VSCode를 WSL에 연결

- uv 설치 + 가상환경 만들기

- PyTorch 설치

- 확인

처음 하면 시간이 꽤 걸립니다. 급하게 넘기지 말고 각 단계의 확인 항목을 꼭 통과하고 넘어가세요.

## 1. 왜 윈도우에서 바로 안 하고 리눅스를 쓰나요?

AI·딥러닝 도구들은 거의 다 리눅스에서 먼저 만들어지고, 윈도우는 나중에 지원되거나 아예 지원되지 않습니다.
실무에서도 AI 개발은 리눅스에서 하고, 여러분이 취업해서 만날 서버도 대부분 리눅스입니다.

그런데 우리 PC는 윈도우죠. 그래서 윈도우 안에 리눅스를 하나 띄워서 거기서 작업합니다.
그 기능이 WSL(Windows Subsystem for Linux)입니다.

오늘 배울 내용만 놓고 보면 윈도우에서도 됩니다.
하지만 몇 주 뒤 큰 언어 모델을 다룰 때 반드시 막힙니다. 그때 옮기면 훨씬 번거롭습니다.

### WSL을 이해하는 그림

집(윈도우) 안에 방(리눅스)을 하나 더 만드는 것이라고 생각하면 쉽습니다.

- 방에는 별도의 문(터미널)이 있고, 안에 자기만의 파일과 프로그램이 있습니다.

- 두 공간은 파일을 주고받을 수 있지만 기본적으로 다른 공간입니다.

|

| 알아둘 것
| 설명

| WSL2
| 버전 2. 진짜 리눅스 커널이 돌아가서 그래픽카드를 쓸 수 있습니다.

| Ubuntu
| 리눅스의 종류(배포판) 중 하나. 우리가 쓸 것.

| 파일 공간이 둘
| 윈도우 C:\ 와 리눅스 /home/ 은 다른 곳입니다.

⚠️ 가장 중요한 습관: 작업 파일은 반드시 리눅스 안(~/)에 두세요.
윈도우 드라이브는 리눅스에서 /mnt/c/... 로 보이는데, 이 경로는 파일 읽기·쓰기가 몇 배 느립니다.
"바탕화면에 폴더 만들어서 작업"하면 안 됩니다.

## 2. 1단계 — 내 그래픽카드 확인

시작 → powershell 입력 → Windows PowerShell 실행

nvidia-smi

이런 표가 나옵니다:

+-----------------------------------------------------------------------------------------+
| NVIDIA-SMI 610.62 KMD Version: 610.62 CUDA UMD Version: 13.3 |
|-----------------------------------------+------------------------+----------------------+
| 0 NVIDIA GeForce RTX 2070 ... WDDM | 00000000:01:00.0 On | N/A |
| 0% 51C P8 20W / 215W | 345MiB / 8192MiB | 17% Default |
+-----------------------------------------------------------------------------------------+

여기서 세 가지를 확인하세요. 나중에 필요합니다.

|

| 항목
| 예시
| 뜻

| GPU 이름
| RTX 2070 SUPER
| 내 그래픽카드 모델

| Memory
| 345MiB / 8192MiB
| 총 8GB 중 얼마를 쓰고 있는지

| CUDA (UMD) Version
| 13.3
| 드라이버가 받쳐주는 최대 CUDA 버전 ★

드라이버 세대에 따라 Driver Version: ... CUDA Version: ... 으로 보이기도 합니다. 뜻은 같습니다.

### 명령이 안 되면

- nvidia-smi를 찾을 수 없습니다 → NVIDIA 그래픽 드라이버가 없거나 오래된 것입니다. §7 드라이버 설치로 가세요.

- NVIDIA 그래픽카드가 없는 노트북이라면 → 괜찮습니다. CPU로도 수업을 따라올 수 있습니다. 3단계로 넘어가세요.

CUDA가 뭔가요?
그래픽카드로 일반 계산을 하게 해주는 NVIDIA의 기술입니다.
우리는 CUDA를 직접 쓰지 않습니다. PyTorch가 대신 불러줍니다.
그래서 CUDA를 따로 설치할 필요가 없습니다. (많은 블로그가 설치하라고 하지만 우리에겐 불필요합니다.)

## 3. 2단계 — WSL2 + Ubuntu 설치

### 3-1. 이미 있는지 먼저 확인

PowerShell에서:

wsl -l -v

NAME STATE VERSION
* Ubuntu Stopped 2

- Ubuntu 가 보이고 VERSION 이 2 이면 → 이미 설치된 것입니다. 3-4로 가세요.

- 아무것도 없거나 오류가 나면 → 3-2로.

### 3-2. 설치하기

PowerShell을 반드시 "관리자 권한으로 실행" 하세요.
(시작 → powershell 우클릭 → 관리자 권한으로 실행)

먼저 설치할 수 있는 리눅스 배포판 목록을 봅니다:

wsl --list --online

NAME 칸에 Ubuntu 가 있습니다. 이걸 콕 집어 설치합니다:

wsl --install -d Ubuntu

뒤에 아무것도 안 붙인 wsl --install 만 쳐도 기본값으로 Ubuntu가 깔립니다.
-d Ubuntu 는 어떤 배포판인지 분명히 지정하는 것뿐 — 둘 다 결과는 같습니다.
이 한 줄이 필요한 것을 전부 설치합니다(WSL 기능·리눅스 커널·Ubuntu 본체).

설치가 끝나면 반드시 재부팅하세요.

재부팅 뒤, 배포판을 여러 개 깔았다면 wsl 만 쳤을 때 열릴 기본 배포판을 Ubuntu로 지정해 둡니다:

wsl --set-default Ubuntu

Ubuntu 하나만 깔았으면 이 줄은 없어도 됩니다. 여러 개일 때만 의미가 있습니다.

### 3-3. 버전이 1이라면

wsl --set-version Ubuntu 2
wsl --set-default-version 2

### 3-4. 첫 실행 — 리눅스 계정 만들기

우분투에 들어가는 방법은 여러 가지, 아무거나 하나면 됩니다:

- 시작 메뉴에서 Ubuntu 검색 → 실행

- PowerShell/터미널에서 wsl (기본 배포판) 또는 wsl -d Ubuntu

- Windows Terminal 을 쓴다면 위쪽 ∨ 드롭다운 → Ubuntu

처음 실행하면 계정을 만들라고 합니다:

Enter new UNIX username: student
New password:
Retype new password:

⚠️ 비밀번호를 칠 때 화면에 아무것도 나타나지 않습니다.
* 표시조차 없습니다. 고장이 아니라 리눅스의 정상 동작입니다. 그냥 치고 엔터를 누르세요.
이 비밀번호는 나중에 관리자 명령(sudo)을 쓸 때 필요하니 잊지 않게 적어두세요.

계정을 만들면 프롬프트가 이름@컴퓨터:~$ 모양으로 바뀝니다. 여기부터가 리눅스 안입니다.
제대로 들어왔는지 두 줄로 확인하세요:

whoami # 방금 만든 계정 이름이 나옵니다
pwd # /home/이름 ← 리눅스 홈. /mnt/c/... 가 아니어야 정상

이 창(우분투 터미널)이 앞으로 모든 실습을 하는 곳입니다. 윈도우 명령창(PowerShell)과는 다른 공간이에요.
exit 를 치면 나가고, 위 방법으로 다시 들어오면 계정을 또 만들지 않습니다(한 번만 만듭니다).

### 3-5. 최신 상태로 만들기

Ubuntu 터미널에서:

sudo apt update && sudo apt upgrade -y

sudo = 관리자 권한으로 실행 (비밀번호를 물어봅니다)
apt = Ubuntu의 프로그램 설치 도구

### 3-6. 리눅스 안에서 그래픽카드가 보이는지 확인 ★

Ubuntu 터미널에서:

nvidia-smi

윈도우에서 봤던 것과 거의 같은 표가 나오면 성공입니다.

드라이버를 리눅스에 설치하지 않았는데 왜 보이나요?
윈도우에 깔린 드라이버를 리눅스가 빌려 쓰기 때문입니다.
⚠️ WSL 안에 NVIDIA 드라이버를 설치하면 오히려 망가집니다. 절대 하지 마세요.

## 4. 3단계 — VSCode를 WSL에 연결

VSCode는 윈도우에 설치하고, 그 안에서 리눅스에 접속하듯 작업합니다.

### 4-1. 확장 설치

- VSCode 실행

- 왼쪽 확장(Extensions) 아이콘 (Ctrl+Shift+X)

- WSL 검색 → Microsoft가 만든 "WSL" 설치

### 4-2. 연결하기

방법 1 (가장 쉬움) — Ubuntu 터미널에서:

cd ~
code .

처음에는 필요한 파일을 자동으로 내려받습니다(수십 초). 다음부터는 빠릅니다.

방법 2 — VSCode 좌하단의 파란 >< 버튼 → Connect to WSL

### 4-3. 연결됐는지 확인

|

| 확인할 것
| 정상

| VSCode 좌하단 표시
| WSL: Ubuntu

| 터미널(Ctrl+`)에서 pwd
| /home/내이름 (/mnt/c/... 가 아님)

### 4-4. ⚠️ 여기서 많이 헤맵니다 — 확장을 리눅스 쪽에도 설치

VSCode 확장은 "윈도우용"과 "WSL용"이 따로입니다.

WSL에 연결한 뒤 확장 탭을 보면 "WSL: Ubuntu에 설치" 버튼이 보입니다.
Python, Jupyter 확장은 이 버튼을 눌러 리눅스 쪽에 설치해야 동작합니다.

이걸 모르면 "확장을 깔았는데 파이썬이 인식이 안 돼요"가 됩니다.

## 5. 4단계 — uv 설치와 가상환경

### 5-1. uv란?

파이썬 패키지와 가상환경, 그리고 파이썬 버전까지 관리해주는 빠른 도구입니다.
우리는 uv로 Python 3.12를 쓸 겁니다. (시스템에 깔린 파이썬이 너무 최신이면 일부 패키지가 아직 지원하지 않을 수 있어서요.)

### 5-2. 설치

Ubuntu 터미널에서:

curl -LsSf https://astral.sh/uv/install.sh | sh

설치 후 터미널을 다시 열거나:

source ~/.bashrc
uv --version # 버전이 나오면 성공

### 5-3. 작업 폴더와 가상환경 만들기

# 작업 폴더 — 반드시 리눅스 홈(~) 아래에!
mkdir -p ~/p3-llm/c1-pytorch && cd ~/p3-llm/c1-pytorch

# Python 3.12로 가상환경 생성 (uv가 3.12를 알아서 가져옵니다)
uv venv --python 3.12

# 활성화 — 프롬프트 앞에 (c1-pytorch) 또는 (.venv) 가 붙으면 성공
source .venv/bin/activate

# 확인
python --version # Python 3.12.x

가상환경을 왜 쓰나요?
프로젝트마다 필요한 라이브러리 버전이 다릅니다. 전부 한곳에 설치하면 하나를 고치다 다른 게 깨집니다.
가상환경은 이 폴더 전용 파이썬 상자입니다. 망가지면 상자만 지우면 됩니다(rm -rf .venv).

⚠️ 터미널을 새로 열 때마다 활성화해야 합니다.

cd ~/p3-llm/c1-pytorch && source .venv/bin/activate

⚠️ uv로 만든 환경에는 pip이 없습니다.

python -m pip install torch # ❌ 안 됩니다
uv pip install torch # ✅ 이렇게 씁니다

## 6. 5단계 — PyTorch 설치

### 6-1. 내 드라이버에 맞는 것을 고릅니다

PyTorch는 CUDA 버전별로 다른 빌드가 있습니다.
§2에서 확인한 CUDA (UMD) Version 을 보고 고르세요.

|

| nvidia-smi의 CUDA 버전
| PyTorch 설치 명령

| 13.0 이상 (강의장 = 13.3)
| uv pip install torch

| 12.6 ~ 12.9
| uv pip install torch --index-url https://download.pytorch.org/whl/cu126

| NVIDIA 그래픽카드 없음
| uv pip install torch --index-url https://download.pytorch.org/whl/cpu

강의장에서는 이 한 줄이면 됩니다 (실습에 필요한 나머지 패키지까지 함께):

uv pip install torch numpy scikit-learn matplotlib

⚠️ torch 만 설치하면 numpy 가 함께 깔리지 않습니다.
실습 코드가 numpy를 쓰므로 위처럼 같이 설치하세요. (실측 확인)

다운로드가 수 GB입니다. 강의장 실측으로는 1분 안팎이 걸렸습니다.

### 6-2. ⚠️ 왜 이걸 신경 써야 하나요

드라이버가 감당 못 하는 버전을 설치하면 —
설치는 성공하고 에러도 안 나는데, 그래픽카드만 인식이 안 됩니다.
초보자가 가장 오래 헤매는 문제입니다. 그래서 설치 직후 반드시 다음 단계로 확인합니다.

### 6-3. 그래프 그리기 준비 (한글 깨짐 방지)

학습 결과를 그래프로 볼 때 필요합니다. 한글 폰트를 같이 설치해야 글자가 안 깨집니다.

matplotlib 은 앞 단계에서 이미 설치했습니다. 한글 폰트만 추가로 설치하면 됩니다.

# 한글 폰트 (이걸 안 하면 그래프의 한글이 네모(□)로 나옵니다)
sudo apt update && sudo apt install -y fonts-nanum

# matplotlib이 폰트 목록을 새로 읽도록 캐시를 지웁니다
rm -rf ~/.cache/matplotlib

sudo 는 비밀번호를 물어봅니다. WSL 처음 설정할 때 만든 그 비밀번호입니다.
(화면에 표시되지 않으니 그냥 치고 엔터를 누르세요)

왜 깨지나요?
matplotlib의 기본 폰트에는 한글 글자가 아예 없습니다. 그래서 네모로 나오고
Glyph ... missing from font(s) DejaVu Sans 경고가 쏟아집니다.
폰트를 설치한 뒤, 코드에서 koplot.use_korean() 한 줄을 부르면 해결됩니다.
(실습 코드에 koplot.py 가 들어 있습니다)

설치하지 않아도 실습은 그대로 진행됩니다. 그래프 라벨만 영어로 쓰면 됩니다.

## 7. 6단계 — 확인

~/p3-llm/c1-pytorch/check.py 파일을 만들고:

import torch

print("PyTorch 버전:", torch.__version__)
print("CUDA 사용 가능:", torch.cuda.is_available())

if torch.cuda.is_available():
print("GPU 이름:", torch.cuda.get_device_name(0))
total = torch.cuda.get_device_properties(0).total_memory / 1024**3
print(f"VRAM: {total:.1f} GB")
else:
print("→ GPU를 못 찾았습니다. CPU로 진행합니다 (수업은 문제없음)")

실행:

python check.py

성공하면:

PyTorch 버전: 2.13.0+cu130
CUDA 사용 가능: True
GPU 이름: NVIDIA GeForce RTX 2070 SUPER
VRAM: 8.0 GB

🎉 여기까지 나오면 환경 구축 완료입니다.

CUDA 사용 가능: False 가 나와도 수업은 그대로 따라올 수 있습니다.
오늘 쓰는 데이터는 아주 작아서 CPU로 1초면 끝납니다. 조급해하지 마세요.

## 8. 문제 해결

### 설치 관련

|

| 증상
| 원인
| 해결

| wsl -l -v 에 아무것도 없음
| WSL 미설치
| 관리자 PowerShell에서 wsl --install → 재부팅

| Ubuntu 첫 실행 시 비밀번호가 안 쳐지는 것 같음
| 정상입니다 (화면에 표시 안 됨)
| 그냥 치고 엔터

| nvidia-smi를 찾을 수 없습니다 (WSL 안에서)
| 윈도우 드라이버 문제
| 윈도우에 드라이버 설치 → PowerShell에서 wsl --shutdown 후 재시도

| externally-managed-environment
| 가상환경을 활성화 안 함
