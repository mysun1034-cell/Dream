# 학습자 가이드 — 어텐션의 등장

문장을 벡터 하나에 눌러 담지 않기

## 오늘 알아야 할 것

- 번역처럼 문장을 받아 문장을 내는 문제는 왜 인코더·디코더로 나누는가

- 인코더가 넘기는 context vector가 무엇인가 (앞 시간의 h_n)

- 병목 — 입력은 길어질 수 있는데 context는 크기가 고정이다

- 어텐션 — 왜 가중 평균이어야 하는가 (스스로 유도할 수 있게)

- 어텐션 가중치를 손으로 계산하기

- 정렬 히트맵 읽기

오늘 설치할 것: 없습니다. 앞 시간 가상환경을 그대로 씁니다. 학습은 CPU로 10초 안팎입니다.

## 1. 문제가 바뀌었습니다

| 라벨 1개 (긍정/부정)

앞 시간엔 다 읽고 판단 하나만 내면 됐습니다. 오늘은 읽은 뒤에 또 써야 합니다.

### RNN 하나로는 안 됩니다

입력: 나는 학생 입니다 (3 단어)
출력: I am a student (4 단어)

RNN은 입력 하나에 출력 하나 — 1:1입니다. 길이가 안 맞습니다.
입력이 끝난 뒤에도 출력을 계속 내야 하는데, 그때는 넣을 입력이 없습니다.

### 그래서 둘로 나눕니다

- 인코더: 끝까지 읽고, 요약 하나를 넘긴다

- 디코더: 그 요약으로 시작해 한 단어씩 낸다

이 구조를 seq2seq 라고 합니다.

## 2. context vector = 앞 시간의 h_n

막연한 개념이 아닙니다. 인코더 RNN의 마지막 은닉 상태입니다.

output, h_n = rnn(x) # 앞 시간에 이걸 받았습니다

# 앞 시간: h_n → 분류기
# 오늘: h_n → 디코더의 시작 상태

은닉 크기가 64라면:

"나는 학생 입니다" → h_n : (64,)
"저는 어제 서울에서 친구를 만났습니다" → h_n : (64,)

둘 다 크기가 똑같이 64입니다.

### teacher forcing — 학습할 때는 정답을 넣습니다

디코더는 자기가 낸 단어를 다음 입력으로 씁니다. 그런데 학습 초기엔 엉터리를 내므로,
첫 글자를 틀리면 뒤가 다 무너져 학습이 안 됩니다. 그래서 학습할 때만 정답을 넣어 줍니다.

[학습 중] 디코더 입력: <시작> I am a ← 전부 정답에서
디코더 정답: I am a student

[추론할 때] 디코더 입력: <시작> I am a ← 자기가 낸 것을 다시

코드에서 dec(yb[:, t], ...) 의 yb 가 정답인 이유입니다.

## 3. 병목

입력 길이엔 상한이 없는데 c 의 용량은 상수입니다.
문장이 길수록 숫자 하나가 짊어질 정보가 늘어납니다.

책을 아무리 잘 읽어도(LSTM), 전할 때 포스트잇 한 장에만 적으면 긴 책일수록 빠지는 게 생깁니다.

### 앞 시간에 배운 것과 무엇이 다른가

|

|
| 무엇에 대한 것인가
|

| 기울기 소실
| 인코더가 읽는 동안 앞을 잊지 않기
| 앞 시간에 해결

| 병목
| 다 읽은 결과를 고정 크기로 넘기기
| 오늘의 문제

LSTM은 읽기를 잘하게 만들었지, 넘기는 통로를 넓히지는 않았습니다.

### 무엇이 필요한가

① 인코더가 읽은 것을 하나로 줄이지 말 것
② 디코더가 필요할 때 필요한 것만 볼 것
③ 디코더가 받는 건 여전히 고정 크기일 것

셋을 동시에 만족시켜야 합니다.

## 4. 어텐션 만들기 ★

### 시도 1 — 전부 넘기자

인코더는 사실 단어마다 은닉을 만듭니다. 마지막 것만 쓰고 나머지를 버렸을 뿐입니다.

나는 → h₁ 학생 → h₂ 입니다 → h₃

막힘. 문장마다 개수가 다릅니다(3단어면 3개, 50단어면 50개). → ③ 위반

### 시도 2 — 평균은?

c = (h₁ + h₂ + h₃) / 3

크기 문제는 풀렸습니다. 막힘. 평균은 셋을 똑같이 중요하게 봅니다.
student 를 쓰려는 순간에도 "입니다"를 같은 비중으로 봅니다. → ② 위반

### 도착 — 가중 평균

c = 0.1·h₁ + 0.7·h₂ + 0.2·h₃

① 안 버렸다 ✓ ② 필요한 것을 더 본다 ✓ ③ 크기 고정 ✓

어텐션은 결국 가중 평균입니다.

### 그 수는 누가 정하나

사람이 정할 수 없습니다. 모델이 정합니다. 그리고 한 벌로 끝이 아니라 출력할 때마다 달라야 합니다.

"I" 를 쓸 때 → "나는" 을 많이
"student" 를 쓸 때 → "학생" 을 많이

### 점수를 매긴다

지금 디코더 상태와 각 입력의 은닉을 함께 넣으면 점수 하나가 나오는
작은 신경망(채점기) 을 답니다. 규칙을 사람이 주지 않고, 번역을 배우며 함께 학습됩니다.

점수₁ = 채점기(디코더 상태, h₁)
점수₂ = 채점기(디코더 상태, h₂)
점수₃ = 채점기(디코더 상태, h₃)

### 왜 softmax인가

가중 평균에 쓰려면 모두 0 이상이고 합이 1이어야 합니다.

그냥 합으로 나누면 안 될까요? 점수가 음수면 무너집니다.

점수 -1.0, 1.0, 0.5 → 합 0.5 → 나누면 -2.0, 2.0, 1.0
↑ 음수 가중치, 1을 넘는 값

softmax 는 한 번에 해결합니다.

- e^x 는 항상 양수

- 합으로 나누므로 합 = 1

- 큰 점수를 더 크게 벌려 줍니다

- 미분 가능 → 채점기를 학습시킬 수 있습니다

## 5. 손으로 계산해 봅시다 ★

주어진 것

h₁ = [1, 0] 점수 2.0
h₂ = [0, 1] 점수 1.0
h₃ = [1, 1] 점수 0.5

1단계 — 지수

e^2.0 = 7.389
e^1.0 = 2.718
e^0.5 = 1.649
─────
= 11.756

2단계 — 나눠서 가중치

α₁ = 7.389 / 11.756 = 0.63
α₂ = 2.718 / 11.756 = 0.23
α₃ = 1.649 / 11.756 = 0.14
─────
합 = 1.00

3단계 — 가중합

context = 0.63·[1,0] + 0.23·[0,1] + 0.14·[1,1]
= [0.77, 0.37]

두 가지를 확인하세요.

- 합이 1입니다. 가중치는 100%를 나눠 주는 것입니다.

- 결과가 h₁ 쪽으로 기울었습니다. 점수가 제일 높았으니까요.

### 코드에서는 이 세 줄

score = self.v(torch.tanh(q + k)).squeeze(-1) # 점수
weights = torch.softmax(score, dim=1) # 가중치 (합=1)
context = (weights.unsqueeze(-1) * enc_out).sum(1) # 가중합

## 7. 코드로 확인 — 01_attention_heatmap.py

작은 번역기(날짜 정규화)를 10초 학습시켜 어디를 보는지 확인합니다.

27 July 2026 -> 2026-07-27
July 27, 2026 -> 2026-07-27
27/07/2026 -> 2026-07-27
2026년 7월 27일 -> 2026-07-27

출력은 늘 YYYY-MM-DD 인데 입력 순서는 제각각입니다.

### 왜 포맷을 섞었나

|

|
| 입력 순서
| 히트맵

| 2026년 7월 27일 (단조)
| 연→월→일, 출력과 같다
| 대각선

| 27 July 2026 (재정렬)
| 일→월→연, 출력과 다르다
| 건너뛰는 무늬

재정렬 입력에서는 출력 연도가 입력 꼬리를, 출력 일이 입력 머리를 봐야 합니다.

### 히트맵 읽는 법

- 행 = 출력 글자 · 열 = 입력 글자

- 밝을수록 그 출력을 낼 때 그 입력을 많이 봤다

### 가중치를 숫자로

출력 '2' (연도 첫 글자)의 어텐션 가중치 — 합 = 0.99
입력[ 0] '2' 0.08
입력[ 1] '7' 0.13
입력[ 8] '2' 0.20
입력[ 9] '0' 0.20
입력[11] '6' 0.23 ← 가장 큼

값이 입력 꼬리(2026 자리)에서 큽니다. 손으로 한 계산을 학습된 채점기가 한 것입니다.

### 배운 적 없는 입력을 넣으면

Jul 27 2026 -> 2026-07-27 (약자 — 운 좋게 맞힘)
2026.07.27 -> 2026-07-27 (점은 배운 적 없음)
99 July 2026 -> 2026-07-09 ← 깨짐

모델은 1~28일만 배웠습니다. 세상에 99일은 없는데 "모르겠다"고 하지 않고
그럴듯한 09 를 만들어 냅니다. 아는 것 밖에서는 자신 있게 틀립니다.

## 다음 시간

오늘 점수는 학습된 작은 채점기가 매겼습니다. 다음 시간엔 그걸 훨씬 간단한 것으로 바꿉니다 —
두 벡터를 그냥 곱합니다(내적).

Attention(Q, K, V) = softmax(QKᵀ / √d) V

Q 는 오늘의 "지금 디코더 상태", K·V 는 오늘의 "각 입력 은닉",
softmax 와 마지막 가중합은 오늘 그대로입니다. 오늘 배운 게 하나도 안 버려집니다.
